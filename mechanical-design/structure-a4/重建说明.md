# A4 重建脚本

原生Blender文件和毫米STL可单独打开。生成器需要项目中已有的A3耳朵模型、PCB坐标表和Gerber图；若只解压模型包，请将它放回当前项目的`mechanical-design/structure-a4/`，或按脚本输入位置恢复这些来源。ZIP未复制原A3整个项目。

在`ESP32-desktop-assistant-handoff`根目录执行下面命令。生成器会覆盖本目录的A4模型，先另存任何手工修改。所有命令都只写A4目录。

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --disable-autoexec --python mechanical-design/structure-a4/scripts/build_a4.py
/Applications/Blender.app/Contents/MacOS/Blender --background --disable-autoexec --python mechanical-design/structure-a4/scripts/check_a4.py
/Applications/Blender.app/Contents/MacOS/Blender --background --disable-autoexec --python mechanical-design/structure-a4/scripts/export_and_views.py
python3 mechanical-design/structure-a4/scripts/verify_stl.py complete-manifest.json stl-verification.json
python3 mechanical-design/structure-a4/scripts/verify_stl.py coupon-manifest.json coupon-verification.json
/Applications/Blender.app/Contents/MacOS/Blender --background --disable-autoexec --python mechanical-design/structure-a4/scripts/check_a4.py -- --motion
/Applications/Blender.app/Contents/MacOS/Blender --background --disable-autoexec --python mechanical-design/structure-a4/scripts/check_a4.py -- --service
/Applications/Blender.app/Contents/MacOS/Blender --background --disable-autoexec --python mechanical-design/structure-a4/scripts/final_audit.py
/Applications/Blender.app/Contents/MacOS/Blender --background --disable-autoexec --python mechanical-design/structure-a4/scripts/render_a4.py
```

检查JSON和最终8张图片，再运行`python3 mechanical-design/structure-a4/scripts/package_a4.py`。打包脚本会验证检查结果、原生文件哈希、STL哈希和渲染时间，拒绝把旧图混进新模型包。

`core.py`复用A3的毫米布尔与几何辅助方法。A4壳体、主板支架、托盘、腿机构和接口参数集中在`build_a4.py`；修改某个包络后需重新运行涉及的装配检查，不能只刷新图片。
