# 开发测试接线与验收

先做三项：裸开发板自检、屏幕/旋钮/按键、单个MG90S。配件到货后可以按本说明直接进行，**不用等定制PCB打样**。目前只完成资料和程序准备，尚无实测结果。

## 1. 工具、排针和线材

- 现有电脑、USB数据线、万用表、能稳压和限流的直流电源、焊接工具。电源最高能到70多V不代表低电压输出能力；要确认3.3V与5V能稳定输出，并先空载用万用表复测。
- 开发板如果长边是空孔：2.54mm、1×20P公排针两条；已焊版本不用再焊。屏幕是原板短边两固定孔间的12孔排针接口，按已有照片为左侧，最终以实物GND/VCC丝印识别；焊1×12P公排针。
- 排针短脚穿板焊接，长脚留给杜邦母头。先焊一针调正后再补齐；焊接时不连接USB、电源或舵机。正反面、伸出方向和插座高度要照实物与外壳空间试配，不能仅凭本文功能序号猜朝向。
- 母对母杜邦线用于开发板与屏幕的信号，尽量10–20cm。舵机插头需要适合的公头转接。电源主线使用短线、可靠端子或配套舵机延长线，不把多根细杜邦线串接作大电流供电。
- 屏幕的VCC、BLK需要从同一外部3.3V分出两路；负极另接屏幕GND和开发板GND。用分线端子/短分线处理，避免裸露线头互碰。

## 2. 先只接开发板

按上级README烧录，串口115200。确认`READY / PASSIVE`，依次运行`selftest`、`wifi scan`、`status`。观察LED短闪，正常启动后按BOOT，确认计数。

预期存储器：Flash=8388608 bytes，PSRAM=8388608 bytes。PSRAM样本测试通过只说明本次64KiB样本读写正常，不是完整存储器压力测试。Wi-Fi扫描不需要账号密码，但也不等于联网功能已开发。

若没有串口：先核对数据线、CH340串口和USB权限/驱动；不先乱改GPIO。下载失败再按BOOT+RESET的步骤进入下载模式。PSRAM为0或复位循环时先核对是否同款板和N8R8配置。

## 3. 屏幕与控件：3.3V

接线以[12针CSV](屏幕12针接线表.csv)和[高清图](diagrams/screen-wiring.svg)为准。SCL=GPIO12、SDA=GPIO11是SPI接口，不是I²C。RES接GPIO21，不接开发板RESET。A=GPIO7、B=GPIO2、PUSH=GPIO38、KEY0=GPIO40。模块自带四路10k上拉，不再另接5V上拉。

1. 拔USB、关外部电源输出，完成全部接线并检查连锡、短路和极性。
2. 电源空载调至3.3V，万用表确认。输出关闭后接回模块。首次排错可先把限流设为约0.1A；这只是起始限制，**不是已测得的模块耗电或额定电流**。
3. USB给主控上电，确认固件处于PASSIVE；随后开启屏幕外部3.3V。主控的3V3/5V排针均不接该外部正极。
4. 测模块VCC、BLK对GND的电压；若处于恒流CC而电压明显掉下，先断电排查短路。确认接线正常后逐步调整限流，记录实际电流，不用升高电压来点亮屏幕。最大全亮电流目前未知。
5. 输入`screen start`。检查完整白边、红绿蓝白色条、横屏文字、ENC/PUSH/KEY0计数。倒置时比较rotation 1与3；黑白反相时比较invert 0与1。如果颜色次序仍错，记录照片和模块批次，再调整驱动，不能将反色设置当成所有颜色问题的修复。
6. 缓慢转10格、反向10格，观察计数是否对称。每格计数不匹配时比较divisor 2与4，记录最终值及方向。按钮按一次只增加一次；长按不连续增加。
7. 结束时输入`stop`，确认回PASSIVE，**先关闭外部3.3V，再拔USB**。背光在关外部电源前仍亮是预期。

控件上拉连在屏幕VCC上，因此屏幕带电而主控USB断开时，仍可能经信号给未供电的主控倒灌。程序没有电源检测或硬件隔离，不能保证USB意外断开时的保护；不要让屏幕单独带电。改线一律全断电。

屏幕只亮背光但不显示时，先核对CS/DC/RES/SCL/SDA和共地。没有MISO，串口显示SCREEN active仅表示初始化命令已发送，不证明屏幕正常。

## 4. 换到双舵机：5V

1. `stop` → 关闭外部电源 → 拔USB，拆掉屏幕全部接线。先把屏幕移出此次测试，避免误接到5V。
2. 空载将电源设为5.0V并复测，再关闭输出接线。现有电源建议在5V时至少有1A、最好2A余量用于双舵机同时动作；这是准备建议，实际启动/负载需求需测量。首次可从约0.5A限流检查空载情况，遇到限流或抖动先查接线、压降和堵转，再决定限流是否合理。
3. 舵机S信号分别接GPIO18（R8，舵机1）和GPIO15（R5，舵机2）；两个舵机正极都接外部5V（两根红线并联），负极接外部电源负极；开发板GND（R9）接同一负极。信号常为橙/黄/白，正极常红，负极常棕/黑；先核对实际插头定义，不能只靠颜色。
4. 卸下舵盘和腿，固定舵机本体，轴不要碰到其他物体。USB主控上电确认PASSIVE，再开外部5V。
5. `servo arm`让两路开始1500μs中位，**初次可能直接转到中位**。随后发`servo pulse 1100`、`servo pulse 1900`看两路同步摆动；再发`servo pulse 0 1100`、`servo pulse 1 1900`确认能分路控制，每次留时间观察。
6. 无有效pulse命令10秒会停发PWM；`status`和错误命令不续时。`servo stop`或`!`可以提前停发。停PWM不等于断电，有些舵机可能暂时保持位置；遇到堵转、抖动、异常发热，先关5V电源。
7. 结束：`stop` → 关5V → 拔USB。记录动作方向、中心位置、启动电流与电源压降。不要在这一步把脉宽改成0–180°全行程扫描。

GPIO18/GPIO15只用于无PCB的临时双舵机测试。八个舵机仍由PCA9685产生PWM，供电另做分配。本轮暂不需要采购PCA9685、UBEC、电池或充电板。

## 5. 合格后进入什么阶段

将真实结果填到[实机验收记录CSV](实机验收记录.csv)。三项通过后，再开发屏幕表情/文字、旋钮菜单和单关节运动逻辑；语音开发再接麦克风、功放和喇叭。双舵机空载通过不代表八舵机电源、整机承重或步态通过。

最终要实测后记录并回填：屏幕安装朝向/反色/每格计数、背光电流、串口识别、实际板卡PSRAM、舵机中心/范围和引线压降。软件默认值是测试起点。
