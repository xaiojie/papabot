到货后先做这一步

  1. 暂不接屏幕、舵机、外部电源。检查开发板外观。
  2. 用现有 USB 数据线连接电脑与开发板 USB-C。
  3. 按 工程说明烧录。macOS 不带 CH34x 驱动，优先用原生 USB 口 /dev/cu.usbmodem* 配 -e lckfb_s3_usbjtag；串口波特率为 115200。
  4. 看到 READY / PASSIVE 后执行下方命令。如果漏掉开机提示，输入 help。
help
selftest
wifi scan
status
wifi connect 你的SSID 你的密码
net test

应该看到什么

  • selftest 显示 ESP32-S3、8 MB Flash、8 MB PSRAM，并检查一块 64 KiB PSRAM。
  • 板载 LED 每秒短闪一次；正常启动后按 BOOT，串口按压计数增加。
  • Wi-Fi 命令扫描 2.4 GHz 网络并逐个打印 RSSI / 信道 / 加密方式，不保存账号密码；RSSI 是天线与 RF 通路的实测依据，扫描结果为零需要结合现场环境判断。
  • wifi connect 做一次性联通测试：口令不回显、只存 RAM、不写 NVS，WiFi.persistent(false) 已显式关闭持久化；复位后即失效。net test 依次验证 DNS、TCP:80 与 HTTP GET（含耗时），比 ICMP 更能说明端到端连通。

这一步能在排针未焊时先做。屏幕与舵机没有接上，便于排除连接问题。

接线和供电

  1. 断开 USB、关闭外部电源。按模块丝印核对 12 个端子并接线。
  2. 外部电源先空载调到 3.3V 并测量，输出关闭后再接 VCC / BLK / GND。
  3. 接 USB，确认固件待机，再开启外部 3.3V。测模块端 VCC、BLK 电压。
  4. 输入 screen start，测试色条、旋钮和两个按键。
  5. 结束时输入 stop，先关外部 3.3V，再拔 USB。

开发板 3V3 输出与外部 3.3V 正极不要相连。电源负极、屏幕 GND、开发板 GND 必须共地。

屏幕测试命令

screen start
status
# 倒置时，再选另一横屏方向：
screen rotation 1
# 黑白反相时，切换观察：
screen invert 0
# 每格计数不符时，比较 2 / 4：
encoder divisor 2
stop

带 # 的行是说明，不要输入。默认横屏 rotation=3、invert=1、divisor=4。方向、颜色和每格计数仍需实物确认。

旋钮计数显示为 ENC；按下旋钮看 PUSH；独立按键看 KEY0。stop 后背光可能仍亮，因为 BLK 直接接 3.3V。

先把屏幕拆下，再测舵机

  1. stop → 关外部电源 → 拔 USB。拆下屏幕全部接线。
  2. 把外部电源调到 5.0V，测量后关闭输出，再接两个舵机。
  3. 两个舵机的正负线都直接去电源（红色线 5V 并联）。GPIO18 / GPIO15 只传信号，开发板 GND 接电源负极。
  4. 首次拆下舵盘和腿，固定舵机本体。接 USB 后再开 5V，输入 servo arm。

启用时两个舵机可能直接回到中位。舵机电流不经过开发板、普通面包板电源条或多段细杜邦线。

双舵机命令

servo arm
servo pulse 1100
servo pulse 1900
servo pulse 0 1100
servo pulse 1 1900
servo stop

servo pulse <us> 动两路；servo pulse <编号> <us> 只动一路（0=GPIO18，1=GPIO15）。每条命令之间观察约一两秒；允许 1000–2000μs。10 秒没有有效脉宽命令会停发 PWM，再次测试须重新 servo arm。

! 不用按回车即可停发 PWM。停止信号不等于断电，若持续抖动、发热或堵转，关闭 5V 电源检查。

现有电源的 5V 电流能力要核实，两个舵机同时动建议留 2A 以上余量；实际需求以测量为准。

排针和连接线，准备这些就能开始

焊在哪里

  • 开发板：若两条长边是空孔，每边焊 1×20P、2.54mm 排针。已焊版本不用重复。
  • 屏幕：在原板左侧短边、两个固定孔之间的 12 孔接口，焊配套 1×12P、2.54mm 排针。先对照 GND / VCC 丝印，确认排针伸出方向。
  • 短脚穿 PCB 焊接，长脚用来插杜邦母头；最终外壳高度与朝向还需按实物试装。

用哪些线

  • 屏幕 ↔ 开发板：母对母杜邦线，优先短线约 10–20cm。
  • 舵机母插头 ↔ GPIO / 接头：适当公头转接；正负主线用短线和牢靠的电源接头。
  • 电源 ↔ 模块：匹配电源端子的引线、分线端子；将一组 3.3V 分给屏幕 VCC 和 BLK。
  • 复用现有 USB 数据线；本次无需电池、充电板或定制 PCB。

先焊一针调正，再焊其余。断电检查焊点、相邻脚连锡与正负极短路。图中的编号是功能顺序，不可据此猜正反面。
