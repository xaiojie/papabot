## 怎样导入

全量Excel的第一个工作表为 **BOM导入_全量**，第1行就是表头，没有标题或合并单元格。前7列按用户当前页面排列：

| Excel字段 | 对应网页字段 | 处理方式 |
|---|---|---|
| 原型号 | 原型号 | 已查具体型号填写；未定型号留空，需求放在原参数 |
| 原品牌 | 原品牌 | 仅填已知品牌；所选MG90S未证明是TowerPro原厂，未补该品牌 |
| 原封装 | 原封装 | 未核实封装留空，不把袋装、整板尺寸当芯片封装 |
| 原参数 | 原参数 | 部件用途、规格与包装单位 |
| 原C编码 | 原C编码 | 仅9项查到的立创编号；外采和未定项不编造C码 |
| 单套用量 | 单套用量 | 本项目1台的数量，单位见后面的单位列 |
| 备损量 | 备损量 | 按1套采购计算，含MOQ多买余量及备件，为绝对数量 |

导入时选择首表，采购套数设 **1套**。例如PM2X6螺丝：单套20＋备损80＝购买100；1000µF电容：单套2＋备损3＝购买5。不要把“建议采购数量”再叠加进单套用量。FIT0030的“3包”表示30根线。

本轮未上传验证字段映射。若界面把备损量解释为百分比，则不要映射这一列；仅就1套采购而言，可以把“建议采购数量”映射为单套用量，备损设0。若增加套数，应重新按需求和MOQ计算。

外采和未定项不能保证在立创自动匹配。全量表保留它们，是为了覆盖整套配件和选型进度；不要把自动推荐的裸PCA9685/MAX98357A等芯片当成品模块。空型号行是否被网页保留也需要导入预览核对，Excel“全部43项总表”始终保留完整记录。

若只匹配已有C码，使用单独的9项文件。它包括保险/保险座等条件候选及MRO螺丝，并不表示这些器件已通过整机适配；若云BOM无法匹配MRO，按链接在工业品核对。在线匹配结果与结算数量仍需查看。
