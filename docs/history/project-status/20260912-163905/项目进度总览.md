### 1.5 integrated-v1（单板全集成 · 新方案）

**动机**：把原来分散的模块（充电板、舵机降压、逻辑降压…）整合到一块 PCB

**已完成：**
```
✅ 嘉立创EDA 里的原理图
   工程 DesktopAssistant_Integrated  (50ae04bdafb74b93b94b7cc4c08171e1)
   58 元件 / 225 网络端口 / 223 导线 / 50 种网络 / 10 个区块
   图纸 A3
   DRC: 0 致命错误 · 0 错误 · 2 个建议性警告
```

**未完成：**
```
❌ PCB 导入 —— pcb_Document.importChanges() 返回 true 但 PCB 里 0 元件
   试过：无参 / 传原理图页 UUID / 传 Schematic UUID / 先存原理图再导
   待查：是否弹了确认对话框
```

**⚠️ 两个必须先解决的问题：**
1. **HY2213 引脚定义未核实** —— 官方手册是 PDF 抓不到，`BAL_GATE1/2` 目前标 NC
2. **BOM 里 HY2213-AB3B 要改成 BB3A** —— AB3B 是 P-MOS 版，配不上 N-MOS 的 AO3400A

**结论**：`integrated-v1` 是**探索性方案**，在 PCB 导出验证完成前，**RevB 仍是主交付版本**。

RAM    [==        ]  22.3%   (73,112 / 327,680 字节)

**三个关键技术决定**（都有实测支撑）：

- **串口实时取景**：RLE 编码把单帧从 312KB 压到 6.8KB，**17.8fps**
