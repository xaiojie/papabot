## 检查结果及边界

1. 原理图导出网表与接口定义核对：98个焊盘逐一匹配，没有网络名错误。
2. 原理图与PCB的21个板上元件唯一ID一致；12个NC焊盘保持空置。
3. 从原生EDA重新读取全部焊盘、铜线、过孔和板框，使用连续几何而非网格近似验证：25/25网络连通；所有铜线和过孔均接入焊盘，没有孤立铜。没有发现异网短接、线宽、铜到板边或螺钉头避铜违规。
4. 实际最小异网铜间距为8.009mil；铜到板/槽边最小13.016mil；铜相对半径2.5mm螺钉头的最小额外余量为4.331mil（约0.110mm）。数值基于当前精确原生坐标，不含制造公差。
5. 导入时EDA自动合并/拆分同网线段，过孔查询API按整数mil返回外径/孔径，但已从保存的原生工程确认仍为0.6/0.3mm。因此API返回数据与候选的字面比较并不完全一致；逐网铜轮廓最大偏差仅0.070711mil（约0.0018mm），修改后的真实几何已另行通过验证。详见 `routing-import-check.json`。
6. **原生PCB严格DRC为true，界面全部(0)。** 初始37条连接性提示及1条网表不一致，在应用原理图属性同步后消失，保存重开后仍通过。修复前后全部铜线、过孔、焊盘及网络映射一致；设计规则也逐项一致，没有放宽规则或屏蔽报错。原生内部为何产生旧连接性结果尚无接口证据，不将其归因于已证明的物理断线。
7. **原理图原生严格检查为true，0致命错误、0错误、0警告。** J1/J2按C429947官方目录补齐属性，器件名恢复为制造商型号，图面仍用Value显示MCU_LEFT_20P/MCU_RIGHT_20P。保存重开后通过；两条信息仅为检查开始/完成日志。本版以模块连接器为边界，检查通过不代替模块内部电路及整机负载实测。
8. Gerber ZIP完整性通过，包含上下铜层、上下阻焊、上下丝印、板框和钻孔；板框80×32mm、U形开口、4个Ø3.2mm非金属孔及122个金属孔（98元件孔+24过孔）已与工程核对。独立过孔钻孔文件是金属孔文件中24孔的重复子集，勿另行叠加加工。详见`gerber-export-check.json`。
9. 已修复原生“一键导出”提示没有板框层线条的问题：原8段独立LINE虽进入API导出的Gerber，却未被原生尺寸检查识别。现用同一路径的1个闭合POLY替代。原生导出显示估算79.985×31.979mm，实际Gerber仍为80×32mm；点击导出并执行DRC后正常进入系统保存窗口，不再出现缺板框警告。铜线、元件、过孔、焊盘与规则均未改动。详见`outline-recognition-check.json`。

打样前需实物复核模块针序、电压、主控排针方向和高度、天线避空及开口铣刀内角。板框尺寸目前为PCB候选，3D外壳配合尚未验收。完整接线和首次上电步骤见 `装配与上电核对.md`。
