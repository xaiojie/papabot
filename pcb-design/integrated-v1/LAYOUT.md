## 四、电源铺铜策略

### 顶层（信号 + 5V）
```
5V 舵机铺铜：≥4mm 宽（2oz），从 DFR0753 输出 → 8 个舵机座
            走"树形"分配，不串联
```
### 底层（GND 整片）
```
除必要跳线外，整片 GND 铺铜 —— 这是 RevA 的教训（当时没有地平面）
```

### 关键散热
```
DFR0753 背面散热焊盘 → 打 6-9 个 Ø0.3mm 散热过孔 → 连到底层 GND 铺铜
```

## 五、布局原则

| # | 原则 | 原因 |
|---|---|---|
| 1 | **大电流区与信号区物理分开** | 舵机噪声不窜进 I2S/SPI |
| 2 | **电池输入 → 保护 → 开关 → 降压 单向排列** | 走线短、回路面积小 |
| 3 | **DFR0753 靠近舵机座** | 5V 路径越短压降越小 |
| 4 | **逻辑降压靠近开发板** | 逻辑 5V 走线短 |
| 5 | **PCA9685 靠近舵机座，但要和 5V 功率路径分开** | 只出信号 |
| 6 | **去耦电容紧贴各自负载** | 1000µF 贴 DFR0753 输出，470µF 贴逻辑 5V |
| 7 | **屏幕接口放在板边** | 排线最短，方便装配 |
| 8 | **EC11 位置由前面板决定** | 需要和结构件对齐 |
