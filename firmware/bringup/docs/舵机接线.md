# 舵机怎么接线（2 个舵机 · HW-793 独立供电）

---

# 一、舵机三根线是什么

MG90S 的标准配色：

| 线色 | 名字 | 接什么 |
|---|---|---|
| **棕色**（或黑）| **GND** | 电源负极 |
| **红色**（中间）| **V+** | 电源正极，**4.8–6V** |
| **橙色**（或黄/白）| **信号** | PWM 信号，3.3V 电平 |

**⚠️ 不同厂家颜色可能不一样，以舵机屁股上的丝印/标签为准。**
**接反会立刻烧舵机。**

# 二、接线表（2 个舵机）

## 电源（都从 HW-793 取）

| 舵机 | 红线 V+ | 棕线 GND |
|:--:|---|---|
| 舵机 1 | HW-793 **红排针 上排 5V** | HW-793 **红排针 下排 GND** |
| 舵机 2 | 同上（并联到同一孔）| 同上（并联到同一孔）|

**两个舵机的电源并联到 HW-793 的 5V 排针上。**

## 信号

| 舵机 | 编号 | 信号线 | 开发板位置 |
|:--:|:--:|---|---|
| **舵机 1** | `servo0` | **GPIO18** | 右列第 8 个孔（丝印 **18**）|
| **舵机 2** | `servo1` | **GPIO15** | 右列第 5 个孔（丝印 **15**）|

> ✅ **两个固件都已支持双舵机（2026-09-14）**：
> `bringup`（实机自检）和 `assistant`（产品/网页控制台）都支持，
> 语法略有差异，见下方「七、双舵机命令」。

# 三、⚠️ 三个必须注意的点

## ① 绝对不能从开发板取舵机电源

```
MG90S 空载 ~200mA，堵转可达 1A 以上
开发板的 5V/3V3 是 USB 或 LDO 出来的，带不动
```

**从开发板取舵机电源的后果**：
- 开发板电压被拉低 → **反复重启**
- 严重时烧 LDO

**必须从 HW-793 取** ✓

## ② GND 必须共

```
HW-793 的 GND  ↔  开发板的 GND
```

**你之前接 HW-793 给开发板供电时已经连了** ✓
**但如果舵机的 GND 只接了 HW-793，而开发板 GND 断开了，舵机会乱抖或不转。**

## ③ 一定要并一个大电容

```
在舵机附近的 5V 和 GND 之间并：
  470µF ~ 1000µF 电解电容
  （正极接 5V，负极接 GND）
```

**为什么**：舵机启动瞬间电流冲击很大，会把 5V 拉低一瞬。
**没有电容的话，同一个 5V 上的开发板可能被拉复位。**

# 四、两种供电方案（推荐第二种）

## 方案 A：简单，但互相干扰

```
HW-793 红排针 5V ──┬── 开发板 R17
                   ├── 舵机1 红线
                   └── 舵机2 红线

HW-793 红排针 GND ─┬── 开发板 R20
                   ├── 舵机1 棕线
                   └── 舵机2 棕线
```

**问题**：舵机电流波动会干扰开发板，可能重启。

## 方案 B：分开供电（推荐）⭐

**HW-793 有三路独立输出，正好用上：**

```
红排针 5V   →  只给开发板        （干净）
黄排针 ADJ  →  只给两个舵机       （可调，调到 5V）
两边 GND 必须连在一起             （共地）
```

**怎么把 ADJ 调到 5V：**
```
1. 万用表接 黄排针 上排 ↔ 下排
2. 转那个蓝色电位器（W103 10k）
3. 调到 5.0V（舵机允许 4.8–6V）
```

**⚠️ 两个 5V 的【正极不能并联】，但【GND 必须连一起】。**
（集成板就是这么设计的：两路 5V 共地、正极分开）

# 六、多路舵机（已支持 2 路）

**两个固件的真值源不一样：**

| 固件 | 真值源 | 生成方式 |
|---|---|---|
| `bringup`（实机自检） | `wiring.json` 的 `servo` 段 | `scripts/generate_wiring.py` 生成 `include/board_config.h`，**不要手改生成的头文件** |
| `assistant`（产品） | `include/config.h` | 手写 |

`bringup/wiring.json` 里现在是这样（生成的 `board_config.h` 会得到 `SERVO_COUNT=2`、
`SERVO_GPIO=18`、`SERVO_GPIO2=15`）：

```json
"servo": {
  "count": 2,
  "gpio": 18, "position": "R8",
  "gpio2": 15, "position2": "R5",
  "minimum_us": 1000, "maximum_us": 2000
}
```

`assistant/include/config.h` 里是这样：

```cpp
constexpr int SERVO_COUNT = 2;
constexpr int SERVO_PINS[SERVO_COUNT] = {18, 15};
```

**要加第三路**：bringup 在 `wiring.json` 里加 `gpio3`/`position3` 并把 `count` 改成 3
（`generate_wiring.py` 里的 GPIO 冲突与位置校验已按后缀循环处理）；assistant 改 `SERVO_COUNT` 和数组。
**命令、状态打印、斜率控制全是循环处理的**，其余代码不用动。

| 编号 | 引脚 | 开发板位置 |
|:--:|:--:|---|
| `servo0` | GPIO18 | 右列第 8 个（丝印 18）|
| `servo1` | GPIO15 | 右列第 5 个（丝印 15）|

## 为什么选 GPIO15/16

```
✅ 都在右列、挨着、方便接排针
✅ 空闲（没被屏幕/旋钮/麦克风占用）
✅ 非 strapping 脚
✅ 不被 Octal PSRAM(GPIO33-37) 和原生 USB(GPIO19/20) 占用
✅ ESP32-S3 任意 GPIO 都能做 LEDC PWM
```

# 七、双舵机命令（bringup 实机固件）

bringup 固件已内建**双路**舵机（2026-09-14 落地，单路是更早的临时状态）：

```
servo arm                 两路都上电、回中位 1500µs
servo pulse 1000..2000    两路一起转到该脉宽
servo pulse <i> 1000..2000  只转第 i 路（0=GPIO18，1=GPIO15）
servo center              两路回中位 1500µs
servo stop                两路松力（PWM 关，电源不断）
status                    顺带打印两路 PWM / 当前 / 目标
```

**⚠️ 两套固件的语法是包含关系，别混用：**

| 命令 | `assistant`（产品，网页控制台） | `bringup`（本次实机自检） |
|---|:--:|:--:|
| `servo`（光一个词） | ✅ 显示用法+状态 | ❌ invalid（用 `status`）|
| `servo status` | ✅ | ❌（用 `status`）|
| `servo arm` | ✅ | ✅ |
| `servo arm <n>` | ✅ 只 arm 某一路 | ❌（arm 永远两路一起）|
| `servo center` | ✅ | ✅ |
| `servo pulse <us>` | ✅ 全部 | ✅ 两路 |
| `servo pulse <n> <us>` | ✅ | ✅ |
| `servo stop` | ✅ | ✅ |

**怎么区分「编号」和「脉宽」**：
```
servo pulse 1400       ← 只有 1 个数字 → 当脉宽，作用到两路
servo pulse 1 1900     ← 2 个数字，第一个是编号（必须 0 或 1）→ 只动 1 号
servo pulse 2 1900     ← 编号 2 超范围 → 直接 invalid，不会退回「两路都动」
```

## 实测输出

```
> servo arm
ARMED: servo0=GPIO18 servo1=GPIO15, 1500 us center, 1000..2000 us range. 10 s timeout. ! = PWM off.

> servo pulse 0 1100
servo0 target 1100 us  [millis=27946]

> servo pulse 1 1900
servo1 target 1900 us  [millis=30861]

> servo pulse 1200
servo0+servo1 target 1200 us  [millis=33010]

> status
PWM0=ON pin=GPIO18 current_us=1100 target_us=1100 (external 5 V)
PWM1=ON pin=GPIO15 current_us=1715 target_us=1900 (external 5 V)
```

## 检查

| # | 怎么查 | 正常 |
|:--:|---|---|
| 1 | 万用表量 HW-793 5V 排针 | 5.0V |
| 2 | 量 ADJ 排针（如果用了方案 B）| 调到 5.0V |
| 3 | 量 开发板 GND ↔ HW-793 GND | **导通** |
| 4 | 舵机红线对 GND | 5.0V |

**⚠️ 第一次上电时手别离开电源开关** —— 舵机接反会冒烟。

## ⚠️ 两个操作注意

**① 10 秒超时会自动松力**
```
发出命令后 10 秒内没有新命令 → 自动松力（防止堵转烧线圈）
```
测试时要在 10 秒内连续发命令，否则报「未 arm」，重新 `servo arm` 即可。

**② 开机后等 15 秒再发命令**
```
设备启动 → 连续做天气+额度请求（各阻塞 4 秒）
        → 这期间串口命令要排队
```

# 八、常见问题

| 现象 | 原因 |
|---|---|
| 舵机嗡嗡响不转 | 信号线没接 / 脉宽超范围（限 1000–2000µs）|
| 舵机抖动 | 5V 带不动，没加电容 |
| **开发板反复重启** | 舵机和开发板共用 5V，电流冲击 → **用方案 B** |
| 舵机发热 | 堵转或长时间保持位置 → 用 `servo stop` 松力 |
| 舵机完全不动 | GND 没共 / 信号线接错 / 舵机坏了 |
