## 文件放置约定

- 新固件功能与测试放入对应固件工程；虚拟环境、编译产物和 Node.js 依赖保留本地。
- 新结构外观草图放 `mechanical-design/concepts/`；结构版本的脚本、STL、渲染和报告放该版本目录内。
- 新采购资料放 `hardware-selection/procurement/<日期>/`；工作簿归到对应 BOM 版本，不再使用会话编号作为根目录。
- 旧进度与交接放 `docs/history/`，不与当前进度并列充当入口。
- 第三方资料也纳入 Git，沿用各模块资料目录，并在 `docs/references/` 汇总来源和查阅入口。
- `.local/` 放本机日志和临时检查资料；`.tools/`、`.workbuddy/`、`.playwright-cli/` 继续作为被忽略的本机环境。
- 其他项目放本仓库外。翻译云两个目录本次已移出，本地内容逐文件校验保留。
- 既有 PCB 与结构历史目录存在脚本依赖，保持模块内部相对位置。工程文件、制造包、STL、图像、BOM 原始表格未重新生成。

## 仓库检查

```sh
python3 scripts/check_repository.py
python3 firmware/bringup/scripts/test_host.py
python3 firmware/assistant/scripts/test_host.py
```

仓库检查覆盖被跟踪的缓存、无关项目、本机绝对符号链接，以及根 README 和本页链接的模块导航。历史快照可能引用已被替代的文件，不作为当前运行入口。
