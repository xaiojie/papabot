# RevA 载板装配与上电核对

**旧版接线说明已停用：** 请用[RevB装配与上电核对](../native-rev-b/装配与上电核对.md)。下文为修改前RevA记录。

**2026-09-09：已确认当前屏幕5V接法需要修订，暂缓下单及连接屏幕。** 模块A/B/PUSH/K0各经10kΩ上拉至VCC，按3.3V供电才能与ESP32输入匹配。当前J3.2仍为5V，下面接线表描述旧PCB实际网络，不表示可以直接接入所选屏幕。修订要求和目标接线见[屏幕资料核对](supplier-review-2026-09-09/屏幕资料核对与PCB修改要求.md)。

这块 PCB 是主控和外接模块的连接载板。主控、屏幕、麦克风、功放、PCA9685、两路稳压模块和电池仍采用当前选定的成品模块。8 个舵机的电源通过外部粗线分配，不经过载板。

## 接线表

元件面观察，方形焊盘为 1 脚。各接口是本载板自定义针序，**按下表逐根接到模块上同名信号**；不能假定现成排线两端针序一致。完整针号及焊盘坐标见 `载板接口与引脚.csv`。

| 接口 | 用途 | 从 1 脚起的针序 |
|---|---|---|
| J1、J2 | 主控两排 20P 插座 | J1 对应主控左排，J2 对应右排；主控元件面朝上、天线朝向两排的 1 脚端；排距 17.78mm |
| J3 | 屏幕，待修订 | 当前实际网络为GND、5V、SCLK、MOSI、RST、DC、CS、空脚；J3.2必须改3.3V后才能按新资料接屏幕，BLK按3.3V高电平接法修订 |
| J4 | PCA9685 逻辑 | GND、3.3V、SDA、SCL、OE；VCC 接 3.3V，V+ 另走舵机电源 |
| J5 | I2S 麦克风 | GND、3.3V、BCLK/SCK、WS、SD、LR；第 6 脚接地，选择左声道 |
| J6 | MAX98357 音频信号 | GND、BCLK、LRC/WS、DIN；功放电源另接 UBEC 分支 |
| J7 | 旋钮及按键输入，原按无源触点设计 | GND、旋钮 A、旋钮 B、GND、旋钮按压、GND、独立按键；连接原模块前先确认3.3V兼容性 |
| J8 | 载板电源输入 | 5V、GND；只接已调到 5V 的逻辑 UBEC 输出 |
| J9 | 电池电压采样 | 总开关后的电池正极、GND；不是给载板供电的入口 |
| JP1 | 主控供电连接 | 5V 逻辑电源、主控 5V；初始不焊跨线 |
| JP2 | 电池采样连接 | 总开关后电池电压、采样分压入口；初始不焊跨线 |

J1/J2 的“左、右”按主控厂家竖直摆放、天线朝上的照片定义；PCB 预览中主控横放，天线朝左。因此两排 1 脚均在板左侧。不要将厂家原理图连接器的针号直接套成本项目 J1/J2 针号。

## 板上和板外元件

- 板上：J1–J9、JP1–JP2、R1–R7、C1/C3/C4，共 21 个元件。R1=100kΩ，R2=33kΩ，R3–R7=10kΩ，C1/C3/C4=100nF。
- C2=470µF/16V，放在板外 UBEC/功放供电分支，靠近功放；电解电容注意正负。它保留在原理图/BOM，但不计入 PCB。
- JP1/JP2 可用短导线跨接，检查通过前保持断开。
- 屏幕原有旋钮和按键留在原板上，藏在可拆前盖内，屏幕竖直朝前。已收到的模块原理图确认：公共端接地，A/B/PUSH/K0各经10kΩ上拉到模块VCC。J7四路输入各经10kΩ上拉到主控3.3V并直连ESP32-S3，因此必须先把屏幕供电设计修订为3.3V；目前不能按旧J3的5V网络连接。修订后A/B/PUSH/K0分别对应J7.2/.3/.5/.7；实际插接方向按模块丝印确认。
- PCA9685 的 OE 为高时禁用输出。板上 R3 将其上拉；若模块自带 OE 下拉，须先核对并去除该下拉，才能实现可靠的上电禁用。

## 电源接法

受保护的 2S 电池 → 7.5A 保险丝 → 总开关 → 两路独立稳压器。充电板接在总开关之前的受保护分支，首版只在关机时充电。

- DFR0753 的 5V/8A 输出供舵机，使用外部粗线星形分配；不要让 8 个舵机的总电流经过载板或 PCA9685 的细铜箔。
- 好盈 3A UBEC 设为 5V，分别接载板 J8 和功放电源。两路稳压器共地，正极输出不能相并。
- J9 接总开关后的电池电压，仅采样。8.4V 经 100kΩ/33kΩ 分压后约为 2.084V，软件读取时需配置 ADC 量程并校准。

## 第一次上电顺序

1. 暂不插主控和外部模块，JP1/JP2 断开；测量 5V、3.3V、GND 间无短路，核对电源接口极性。
2. 单独测量两路稳压器输出均为 5V，再接载板。不要直接把 7.4V 电池接到 J8。
3. 首次烧录时把主控从载板插座拔出，单独连接电脑 USB。厂家电路中 USB VBUS 与主控 5V 排针直接相连，本版没有自动防倒灌电源切换。
4. 拔掉 USB 后，再插主控并接通 JP1；确认 3.3V 正常，再接通 JP2，测量 ADC_BAT 不超过预期值。
5. 仅在屏幕供电、SPI逻辑及A/B/PUSH/K0与J7电压兼容性核对完成后，按确认后的接线依次接屏幕、麦克风、旋钮按键、功放；未确认时保持J7断开。先让 OE 保持高电平，再接 PCA9685 和舵机。先单舵机、小角度测试，再逐步增加数量和负载。

**电池供电时不接电脑 USB。** 单独断开 JP1 不等于已经验证所有外设信号都不会反向供电，因此首次调试采用拔下主控烧录的方式。

## 打样前还要确认

- 原生 DRC 的所有问题已逐项处理；离线几何检查不能替代原生 DRC。
- 用实际主控检查两排插针、1 脚方向、17.78mm 排距和板底元件高度；天线 U 形避空为依据现有尺寸/照片制定的候选，尚未做射频实测。
- 屏幕、麦克风、PCA9685 等实际模块的信号名和供电范围与接线表一致。
- U 形开口内角与板厂铣刀半径相容，安装孔和边缘间距满足选定工艺。
- 定制电池的最终尺寸、电流能力、保护板及插头极性已由商家确认。

3D现行为A3，已完成标称模型配合检查；本文件不表示外壳与载板的实物装配配合已经验收。原生工程中的旧后置控件名称/备注描述的是原电气设计假设，不作为A3机械装配要求。
