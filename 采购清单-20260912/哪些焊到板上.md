# 哪些元器件焊到 PCB 上？

> 对应 Integrated V1.2 无旋钮版（79 器件 / 110×75mm 双层板）
> 整理：2026-09-12

---

## 一句话答案

**立创清单 41 种里，只有 35 种焊到板上；6 种是配套件不焊。淘宝买的全部不焊。**

---

## 一、按「焊不焊」分三类

### ✅ A 类：焊到 PCB 上（35 种 / 79 个器件）

立创清单的**板载部分**，全部要焊到板上。

### ❌ B 类：不焊，是配套件（6 种）

| 立创编号 | 物品 | 实际怎么用 |
|---|---|---|
| `C5329587` | **屏幕 HS24S010B** | 装在前面板，**用 10 针线束**连到板上 J3 |
| `C5360462` | XH2.54 胶壳 10P | 做**屏幕线束**的插头 |
| `C5360454` | XH2.54 胶壳 2P ×2 | 做 J7 / J10 的插头 |
| `C5360455` | XH2.54 胶壳 3P | 做 JBAL 平衡线的插头 |
| `C5360463` | XH2.54 压线端子 ×30 | **压接**到导线上，插进胶壳 |
| `C100114` | 2.54mm 跳线帽 ×5 | **插**在 JP_CHG/JP_LCD/JP_MCU 排针上 |

### ❌ C 类：淘宝买的，全部不焊到主板

| 物品 | 实际怎么用 |
|---|---|
| MG90S 舵机 ×8 | 装在腿上，**插**到 SV1–SV8 |
| I²S 麦克风模块 | 板外模块，**插**到 J4 |
| MAX98357 功放模块 | 板外模块，**插**到 J5 |
| 舵机降压模块 | 板外，接到 J_SRV_IN / J_SRV_OUT |
| 逻辑降压模块 | 板外，接到 J_LOG_IN / J_LOG_OUT |
| **R6 500mΩ 电阻** | ⚠️ **这个要焊！** 只是立创没货才去淘宝买 |
| 电池 / 开关 / NTC / 喇叭 | 板外，分别接 JBAT / J_SW / J7 / 功放 |
| 线材 / 紧固件 | 辅料 |

> ⚠️ **注意 R6**：它是唯一「淘宝买但要焊到板上」的元件。

## 三、嘉立创 SMT 贴片服务覆盖范围

在嘉立创下单 PCB 时，可以勾选 **「SMT 贴片」**：

```
✅ 能自动焊：51 个贴片元件（含 U7 的 0.65mm TSSOP-28）
❌ 不含：28 个插件元件
❌ 不含：R6（立创无货，自己淘宝买的）
❌ 不含：6 种配套件（屏幕/胶壳/端子/跳线帽）
```

**推荐组合：**

| 步骤 | 谁做 |
|---|---|
| 1. PCB 打样 + **SMT 贴片（贴片件）** | 嘉立创 |
| 2. 插件件焊接 | 你自己（或加钱让嘉立创焊） |
| 3. R6 补焊 | 你自己（**唯一要自己焊的贴片件**） |
| 4. 屏幕线束制作 | 你自己（压端子 + 焊排针） |

> 💡 **U7 是 TSSOP-28、0.65mm 脚距，手焊有难度** ——
> 建议**一定选 SMT 贴片**，让嘉立创焊这颗。

---

## 四、你要动手做的焊接/装配

| 任务 | 难度 | 说明 |
|---|---|---|
| **R6 补焊** | ⭐⭐ | 0805 贴片，手动补一颗，简单 |
| **插件件焊接** | ⭐⭐ | 28 个，孔大间距宽，容易 |
| **Type-C 母座**（若没选 SMT）| ⭐⭐⭐ | SMD 但引脚密，需要热风 |
| **U7 TSSOP-28**（若没选 SMT）| ⭐⭐⭐⭐ | 0.65mm 脚距，建议别手焊 |
| **屏幕线束** | ⭐⭐⭐ | 10 根线，压端子 + 焊排针 |
| **电池 XT30** | ⭐⭐ | 粗线，需要大功率烙铁 |

---

## 五、汇总表

| 类别 | 种类 | 器件数 | 焊到板上？ |
|---|---|---|---|
| **立创 · 板载贴片** | 27 | 51 | ✅ 焊（建议 SMT）|
| **立创 · 板载插件** | 8 | 28 | ✅ 焊（手焊）|
| **立创 · 配套件** | 6 | 40 | ❌ 不焊 |
| **淘宝 · R6** | 1 | 1 | ✅ **焊** |
| **淘宝 · 其他** | ~20 | — | ❌ 不焊 |
| | | | |
| **合计要焊到板上的** | **36 种** | **80 个** | |

> 注：79 个板载器件 + R6 = **80 个焊点元件**
> （R6 本来就在 79 里，去淘宝买不影响数量）
