HW-793 → 开发板 供电接线图

用电源模块独立供电，不依托 USB。只接两根线，屏幕和舵机的线一根都不用动。

🔴 USB 和电源模块，同一时刻只能上一个
开发板的 5V 针和 USB VBUS是直连的，板上没有电源切换电路。
两个同时上 = 电源打架，可能倒灌进电脑 USB 口。
插 USB 之前，先把模块的 5V 线拔掉。
💡 红色排针（2 排 × 3 列）的用法
上面那排 = 5V　·　下面那排 = GND —— 两排都能接，随便挑一列。

针脚对照

从哪到哪位置说明
HW-793 红排针 · 上排 5V开发板 R17右列第 17 根
HW-793 红排针 · 下排 GND开发板 R20右列最下面那根

R17 / R20 在哪：开发板元件面朝上、天线朝上、USB 朝下，看右边一列，从上往下数。 R17 印着 5V、R20 印着 GND，两根都在最下面，挨着。

上电前 30 秒检查

#做什么通过标准
1万用表量红排针上排 ↔ 下排≈5.0V（若只有 3.5V，说明模块输入电压不够）
2量 5V 和 GND 之间是否短路（断电时）蜂鸣档不响
3确认 USB 已拔掉必须
4接上模块，上电开发板红 PWR 灯亮、屏幕亮起

要传数据的时候

  1. 拔掉模块的 5V 线（GND 可以留着，不用拔）
  2. 插 USB → 烧录 / 看串口
  3. 拔 USB → 把 5V 线接回去

嫌麻烦？在模块 5V 线上串一个 1N5819 或 SS34 肖特基二极管， 以后就能随便插拔（压降约 0.3V，开发板拿到 ~4.7V，完全够）。二极管的方向：带银色环的一端朝开发板。
