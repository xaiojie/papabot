# PCB与结构的接口提案

2026-09-08，状态：讨论中的首轮接口，不是冻结尺寸。整机坐标沿用用户 Blender 文件：X 左右、Y 前后（前为负）、Z 向上，单位 mm。

从真实保存模型读取：主壳外包络 X[-59,59]、Y[-14.7,38]、Z[30.6,106]；底盖 109×48×3，范围 X[-54.5,54.5]、Y[-12.9,35.1]、Z[29.7,32.7]。电子托板 84×37，XY 范围 X[-42,42]、Y[-8.5,28.5]，最高 Z37.8。详情见 `reports/source-inventory.json`。

建议先把原电子托板改为可拆载板支架，留 **80×32×1.6** 的自研主控载板：板底 Z40，中心 X0 / Y10，器件暂以最高 Z60 作布置预算。此值只描述几何提案，不能承诺所有模块已经装入；PCA、功放、两路降压等走线束另装，实际安装层高待 PCB 布置图返回。

孔位和8mm直径净空均需 PCB 确认；尚未把对应立柱刻进最终底盖。当前候选板底距旧托板最高点仅 2.2mm，意味着不能直接按图叠现成8.5mm排母/柱子后假设高度不变，需要重设计支架的支撑高度；4孔直达工具从底面检修，目标给M3工具约Ø8的直线通路，并按实际螺丝长度确认。

PCB任务已核主控原厂PDF板体 **51.66×20.32mm，2×20P、列距17.78mm、首末孔48.26mm**。若长轴沿X，USB朝侧面，壳体对应侧需要开服务口及USB插头/线缆的直线插拔通道；其大小用真实线头外壳测量，不将外壳孔径等同USB金属口尺寸。天线净空由PCB任务按主控资料反馈；不把电池、金属紧固件或粗供电线贴在天线前。

现有屏幕支撑框到后部Y=-10；在保留完整屏幕PCB且按新决定将旋钮移后之后，可以缩短前盖，但不能自动增加主壳内部底盘面积。显示板右边缘X56，旧壳内壁名义X56.6，余量约0.6mm，螺母、支架和工艺公差均可能要求机身略加宽。

电池目标75×40×20（含保护板/包裹）深40，大于原37mm电子托板，也会与旧PCA、音频占位争空间。暂不安排精配电池托架和固定高度，等待商家实际包络，再按低重心、绝缘、可拆束带及线头弯折重新分层。目标重量≤80g不是已拿到成品的实重。

麦克风旧选型文字写SEN0327/Ø14，但相关资料出现Sipeed I2S_Mic、15.24×9.14×11.2mm、6P2.54的信息差异，商品身份待核。暂不冻结圆形夹座和拾音开口；预留可换小支架方案。喇叭参数Ø23.6×10.4只作商品标称；磁体/焊线/音腔空间需整体核对。

后面板需容纳移出的EC11和独立按键、充电口和总开关及维修开口。对应器件的螺纹、防转面、壳体厚度、引脚端子空间没有实测前，不生成最终固定孔。18AWG电池/舵机线保持独立走线固定，不能以信号杜邦线和排针代替大电流路径。
