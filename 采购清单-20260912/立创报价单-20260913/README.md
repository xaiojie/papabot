## 五、🔍 两个值得考虑优化的项

### ① 保险丝座 ¥24.35 —— 占 10%，偏贵

```
01530008Z  Littelfuse(美国力特)  插件  库存 417   ¥24.35
```

**这是进口 Littelfuse 的正品价。** 国产同规格（Mini Blade 座）淘宝只要 ¥1–3。

**要省的话**：
- 立创搜 `保险丝座 小号 直插` 找国产替代
- 或淘宝买（几块钱）

**但注意**：保险丝座涉及电池主回路安全，**别买杂牌**。

### ② 电感 ¥15.35 —— 进口 Würth

```
74437368022  Wurth(伍尔特)  2.2µH 28A  ¥15.35
```

**这颗是德国伍尔特的高电流电感**，¥15.35 是合理价。
**但 2.2µH / 28A 这个规格国产也有** —— 如果想省可以找国产替代（¥3–6）。

**不过它是 IP2326 升压充电的关键器件**，换之前要核对饱和电流和 DCR。
