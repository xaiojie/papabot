## USB-C 与电源开关

- 整机充电使用主板 **J6**：外接 5V USB-C → IP2326 充电电路 → 2S 锂电池的8.4V充电路径。它不是 ESP32 开发板的下载 USB。
- 主板旋转后 J6 朝向后盖。后盖孔板 R20 的入口为 **17 × 11**，中心 X=−42、Z=83.8，后盖外表面 Y=56。连接器缩在壳内，所以入口按整个插头护套留空，不能改成只有金属头大小的孔。
- 核对量规是14×15×8的护套和8.4×6.5×2.6的金属端，插拔沿Y方向。护套左右、上下标称余量各1.5 mm。使用实际线缆试配R20后再打印整盖。
- 后部拉杆是此前预留的 **S1A 拨杆总电源开关候选件**，不是旋转编码器。电路 J_SW 的两脚为 VBAT_FUSED / VBAT_SW，它串接电池到逻辑、舵机降压模块的正极供电路径。因此保留总开关功能。
- A5 将该候选开关置于 **R08 凹入式开关仓**，拨杆末端与后盖外轮廓齐平，不再外伸。没有擅自换成电流规格未知的小滑动开关；S1A 实际型号、直流额定电流、安装深度和手指操作空间仍需实物确认。
- 充电通路与 J_SW 负载开关路径不同。原设计 JP_CHG 默认断开会禁止充电；模型增加开孔不代表充电已启用或完成台架验证。

采购USB-C C165948与PCB库封装GT-USB-7010E的全部焊盘/固定脚兼容仍待实板核实，本次外壳开孔检查不替代这项核验。

## Blender 打开与辅助线

主文件为 `DesktopAssistant-整机结构-A5.blend`，主场景 `20_A5_COMPLETE_ASSEMBLY`。其他场景包括内部主板、下层模块、爆炸图、拆前盖与打印件总览。

默认视图已关闭 Extras（附加物体）和 Relationship Lines（关系线），摄影棚对象在主场景视口中隐藏，渲染仍可使用。此前截图中的大量黑线主要来自相机视锥、灯光辅助框和对象关系显示，并非模型裂缝或打印路径。需要这些辅助物时可在视口叠加层菜单重新开启。

原生文件以米存储，显示单位为毫米。STL 已经转换成毫米，切片按100%导入，禁止再乘1000。只打印 `stl-complete/` 中的注册零件，REF、DISPLAY_ONLY、相机、灯光、地面均不打印。

## 装配、紧固与拆卸

先装四个髋固定座，再装舵机、原装舵盘与腿件。腿座固定到地板的8颗M3螺钉使用低头规格：头径≤5.5、头高≤1.8，内侧沉孔深2.1，配腿座底面M3螺母槽，避免螺钉头顶住电池托盘。原装舵盘负责与舵机花键连接，模型没有打印花键。

随后安装R21电池托盘、R17/R18降压托架、R06主板架和主板，再装屏幕、麦克风、后盖音频与开关组件，整理线束后合壳。

- R01上壳：底部2×M2.5螺钉；前、后盖各4×M3。
- R06主板架：底部2×M3×10；主板4×M2.5×8，板面头径≤5，不使用大金属垫片。
- 每腿固定座：2×M3×12低头螺钉及M3螺母；舵机、舵盘用实际配套螺钉试配。
- R20充电孔板、R08开关仓：各2×M2×6；R04屏幕压框4×M2×6自攻。
- 屏幕、喇叭、麦克风、电池需软垫，不能以螺丝或硬压框直接压玻璃、振膜、电池软包。

拆卸先断电并断开电池。先拆R20和前后盖，断开相应线束，再上提上壳。取主板须先拔线并卸固定螺钉。

换电池本体可在取下主板及R06后解开绑带操作。若需连R21托盘整体取出，还须卸下R18及UBEC，将托盘沿+X移动2 mm，再向上取出；这是本次检查的托盘拆卸路径。爆炸图展示的是分组位置，不表示所有零件可以同时直接拉开。

## 打印与验证边界

31个独立打印件，5个原尺寸试配件。先试配MG90S髋座、屏幕压框/遮边、USB孔板及主板孔位框，再打印整套。0.4喷嘴、0.2层高可作为起点；承力件优先试用PETG，壳体4道墙、承力腿件6道墙并经实际载荷测试修订。R06、外壳的悬空结构需在切片软件中检查支撑。

检查记录在 `reports/`，最终结果见 `验收摘要.md`。腿部检查只覆盖每腿髋−15/0/+15°、膝−20/0/+20°的离散组合，不证明连续扫掠、四腿同时运动、扭矩或地面接触。软线、手指、工具、实际模块公差、电池尺寸、开关手感和打印强度仍须试装确认。
