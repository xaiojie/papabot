# 谁帮你把元件焊到板子上？

> 对应 Integrated V1.2（79 器件 / 110×75mm 双层板）
> 整理：2026-09-12

---

## 一、三条路对比

| 方案 | 优点 | 缺点 | 推荐度 |
|---|---|---|---|
| **① 嘉立创 SMT**（官方）| 和 PCB 打样一起下，不用来回寄；**支持客供料** | 要按它的格式传文件 | ⭐⭐⭐⭐⭐ |
| **② 淘宝代焊** | 可以「我买好料你帮我焊」，沟通灵活 | 要寄板寄料，两次运费，质量看店 | ⭐⭐⭐ |
| **③ 自己焊** | 最便宜、最可控 | U7 是 0.65mm TSSOP-28，有难度 | ⭐⭐ |

---

## 二、① 嘉立创 SMT（最推荐）

### 关键信息（来自官网）

```
✅ 50 元起贴，1 分钱 1 个焊点
✅ 可接 V割拼板、双面贴、【插件】
✅ 【可接客供元器件】← 淘宝买的 R6 可以一起寄
设备：日本雅马哈高速贴片机，9 条样板流水线
```

### 下单流程

```
1. 嘉立创下单 PCB 打样
2. 勾选「SMT 贴片」
3. 上传三个文件：
     ① Gerber        ← 已有（含锡膏层 GTP）
     ② BOM           ← 已有 → 嘉立创SMT-BOM.csv
     ③ 坐标文件 CPL  ← 已生成 → 嘉立创SMT-坐标文件.csv
4. 系统自动匹配立创元件（我们 42 项里大部分能自动匹配）
5. R6 选「客供料」，把淘宝买的寄过去
6. 插件件选「插件焊接」增值服务（可选）
```

### 我已准备好的文件

| 文件 | 内容 | 用途 |
|---|---|---|
| `嘉立创SMT-坐标文件.csv` | 79 行：位号/X/Y/层/旋转 | 上传 CPL |
| `嘉立创SMT-BOM.csv` | 49 个贴片件：型号/位号/封装 | 上传 BOM |
| `DesktopAssistant_Integrated_Gerber_review.zip` | Gerber 全套（含 GTP 锡膏层）| 上传 Gerber |

> ⚠️ **坐标原点已转换**：原文件原点在**左上角、Y 向下**，
> 嘉立创要求**左下角、Y 向上**，已按 `Y_jlc = 75 - Y_ours` 换算并校验：
> ```
> X 范围 7.0 .. 104.0  （板宽 110）✅
> Y 范围 4.0 .. 71.0   （板高 75） ✅
> USB-C (J6) 落在 y=5.0 → 板底边，和实际布局一致 ✅
> ```

> ⚠️ **旋转角还没核对**。嘉立创的旋转约定可能和 EDA 不同，
> 上传后**在它的预览图里逐颗对一下方向**，特别是：
> U7(TSSOP-28)、U4(VQFN-24)、Q1/Q2(SOP-8)、J6(Type-C)、D2(LED 有极性)

## 三、② 淘宝代焊

### 搜索词（淘宝搜索页要登录，我抓不到直链）

```
PCB代焊
SMT贴片代工
电路板焊接加工
PCBA打样焊接
贴片后焊 插件焊接
```

### 典型服务形态

| 类型 | 说明 | 大概价格 |
|---|---|---|
| 纯贴片代工 | 你寄板+料，他贴 | 几十~几百（看焊点数）|
| 贴片+插件全包 | 全焊好寄回 | 更高 |
| 元件代购+焊接 | 他帮你买料再焊 | 最省事但加价 |

### 寄之前要准备

```
✅ PCB 实物（嘉立创打样的）
✅ 元件实物（编带/管装/散装都要标识清楚）
✅ Gerber 文件（电子版，方便他核对）
✅ BOM（位号 → 型号对照表）
✅ 坐标文件（同上，我已生成）
✅ 装配说明（哪些不焊、哪些方向特殊）
```

### ⚠️ 沟通要点

- **明确 R6 要焊**（不然他可能以为是不焊的备件）
- **明确 XH 胶壳/端子/跳线帽不用焊**（这些是线束件）
- **U7 是 0.65mm TSSOP-28**，问清他有没有这个工艺能力
- **Type-C 母座**要确认方向（板边朝外）
- 问清**会不会清洗助焊剂**（影响外观和可靠性）

## 四、③ 自己焊（如果想动手）

| 元件 | 难度 | 方法 |
|---|---|---|
| 0805/0603/1206 阻容 | ⭐ | 普通烙铁 + 镊子 |
| SOT-23 / SOP-8 | ⭐⭐ | 拖焊 |
| **TSSOP-28 (U7)** | ⭐⭐⭐⭐ | **0.65mm 脚距，建议热风+锡膏** |
| **VQFN-24 (U4)** | ⭐⭐⭐⭐ | **底部散热焊盘，必须热风** |
| Type-C 母座 | ⭐⭐⭐ | 热风 |
| 插件件（28 个）| ⭐⭐ | 普通烙铁，孔大间距宽 |

**推荐**：贴片让嘉立创焊，插件自己焊 —— 最省事又便宜。

---

## 五、我的建议

```
第 1 步  嘉立创下单：PCB 打样 + SMT 贴片
         → 上传 Gerber + BOM + 坐标文件
         → R6 用「客供料」把淘宝买的寄过去
         → 插件焊接服务看预算决定

第 2 步  收到板子后自己补：
         • 插件件（如果没选插件服务）
         • 屏幕线束制作
         • 接模块、电池、舵机

第 3 步  上电调试前先做「裸板阻值检查」
```

**预计 SMT 费用**：79 个焊点 × 0.01 元 + 50 元起贴费 ≈ **几十元**
（具体以嘉立创下单页实时报价为准）
