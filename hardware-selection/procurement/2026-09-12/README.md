## 🔴 下单前必须先决定的两件事

### ① 电池要不要保护板

集成板**自带**过充/过放保护（HY2120-CB）+ 均衡（HY2213-BB3A ×2）。

| 方案 | 买什么 |
|---|---|
| **A** | 带保护板的成品包 → ⚠️ 与板上**重复** |
| **B** ✅ | **裸 2S1P 电芯包**（无保护板）→ 完全用板上保护，**推荐** |

**还要注意接口**：主板 JBAT 是 **XT30**，格氏那块是 **T 插**，需要转接。

### ② 外壳怎么办

新板是 **110×75mm**，原 80×32mm 载板的结构**不兼容**。
`mechanical-design/structure-a3/` 还没适配新板 + 新屏。

**可以先打样焊板调试，外壳后面再设计。**

## 🔄 J6 USB-C 母座换型（2026-09-12 追加）

### 问题：GT-USB-7010E 没货了

```
C2848974   GT-USB-7010E   stockNumber: 0   ❌ 确实没货
```

### 先确认板子到底要什么封装

从 `PCB1_geometry.json` 里把 J6 的 16 个焊盘坐标全扒出来量了：

```
12 个信号脚（贴片）
  间距序列 31.5 / 25.6 / 19.7 / 19.7 / 19.7 / 19.7 / 19.6 / 19.7 / 19.7 / 25.6 / 31.5 mil
  → 常规间距 19.7 mil = 0.50 mm    ← USB-C 标准脚距
  → 跨度 252 mil = 6.40 mm

4 个固定脚（多层）
  x 跨度 340.2 mil = 8.64 mm       ← USB-C 外壳标准宽度
  y 跨度 164.5 mil = 4.18 mm
```

**结论：这是【通用 USB-C 16P 卧贴】封装，不是某家专有。**
（两端间距大是因为 A1/B12、A4/B9 是双针合并焊盘 —— 16P USB-C 的标准做法）

## 🔄 U7 PCA9685 换型（2026-09-12 追加）

### 这个「海外代购」是什么

```
C2688894   PCA9685PW,112   TSSOP-28   U7   NXP(恩智浦)
供货方式：RS Components 代购（海外）
库存：0
```

**它不是「模块」，是裸芯片。**

**PCA9685 是什么：**
- NXP 的 **16 路 12 位 PWM 驱动 IC**，I²C 接口
- 淘宝上卖 ¥8–15 的「**16 路舵机驱动板**」= 这颗芯片 + 外围元件做成的模块
- 集成板把它**直接做在板上**（U7），所以**不需要买模块**，只要裸芯片

> ⚠️ 你原来 BOM 里的 `E04 16路PWM舵机信号模块 ¥8.9` 就是它的模块版 ——
> 集成板已经把这部分做进 PCB 了，**那个模块不用买了** ✓
