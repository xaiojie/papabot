- 麦克风沿用原厂圆形Ø14mm模块，供电1.8–3.3V，本方案接3.3V；SCK/WS/SD为I²S，L/R低电平左声道、高电平右声道。厚度、排针和声孔位置仍需实测。

- DFR0753仍只有1块，用于舵机；官网淘宝参数6–14V输入、5V±1%输出、最大8A。整机5V/6A目标、低2S电压下表现及温升尚未实测。与好盈逻辑UBEC共地，两路5V输出不并联。
