## 二、必须知道的两个坑（打样前要解决）

### ① HY2213 引脚定义未核实

```
官方手册 https://www.hycontek.com.tw/hy_battery/DS-HY2213_EN.pdf
→ 抓取工具不支持 PDF
```

**后果**：`BAL_GATE1/2`（均衡 IC 输出 → 泄放 MOS 栅极）**目前标 NC**。
Q3.1 / Q4.1 打了 `NoConnected` 标记，元件属性里写了 `Assembly note` 警告。

**→ 拿到引脚定义后，把 OUT 脚连到 Q3.1 / Q4.1。**

### ② BOM 里 HY2213 型号选错

```
现在：HY2213-AB3B → P-MOSFET 均衡控制（OUT 输出 H→L 有效）
应改：HY2213-BB3A → N-MOSFET 均衡控制（OUT 输出 L→H 有效）
```

因为均衡 MOS 用的是 **AO3400A（N-MOS）**，与 AB3B 不匹配。
来源：https://www.hycontek.com.tw/en/products-en/3204

## 三、设计本身的关键决定（都已核对官方规格书）

### 电源架构
- **两路 5V 独立**：`+5V_SERVO`（舵机）/ `+5V_LOGIC`（逻辑）
- **只共地，正极绝不并联**
- 舵机典型 2-3A、峰值 6-8A → 顶层铺铜 ≥4mm

### 电池保护（HY2120-AB 替代 PW7120，阈值相同）
- 过充 4.28V/节 = 8.56V，过放 2.90V/节
- AO4406 ×2 背靠背低边，**VM 走线必须对称**（不对称会歪曲电流检测）

### 充电（IP2325 升压）
```
拓扑：VIN → 电感 → LX →（同步开关）→ VOUT → 电池
⚠️ 官方明确：动力类应用必须加 D1 肖特基
⚠️ 引脚：1=VSYS 2=VOUT 3=VSET 4=NTC 5=LED 6=VIN 7=BST 8=LX 9=GND
```

### 叠层
```
2 层 / 1.6mm / 2oz 铜 / 沉金
顶层：信号 + +5V_SERVO 铺铜
底层：完整 GND 平面（RevA 的缺陷就是没有地平面）
板框：110 × 75 mm
```

### 屏幕（已定稿）
```
汉昇 HS24S010B   立创 C5329587
2.4" IPS / ST7789 / SPI / 3.3V / 320×240
43.5 × 72.9 mm，双排 2×10P @2.54mm
只用 8 个信号，FS0/FCS 悬空
引脚：1=GND 2=+3V3 3=SCLK 4=MOSI 5=RST 6=DC 7=CS 8=+3V3
```

## 六、我犯的错（供接手的人避坑）

如果你要用 EasyEDA 的 API 继续做，**这几个坑我踩过，别再踩**：

### 1. `setState_*` 必须配 `done()`
```js
pin.setState_NoConnected(true);
await pin.done();        // 不调 = 完全白改，而且不报错
```

### 2. 坐标吸附
```js
const snap = v => Math.round(v/5)*5;
// 导线终点要 snap（否则端口吸附后差 1 单位不连通）
// 导线起点【不能】snap（否则非网格引脚接不上）
```
**这个坑害我 220 个端口全部悬空、280 条 DRC 信息。**

### 3. 循环里的 `await` 要小心
```js
for (const pin of await c.getAllPins()) { ... }   // ✅
for (const pin of c.getAllPins()) { ... }         // ❌ 拿到 Promise
```

### 4. 批量删除的过滤半径按「目标引脚」算
**我因半径过大误删了三次**（U7 的 PWM0-4、U7 的 GND 脚、J1 的三个信号）。
**删之前先列出「将要删除的东西」，确认无误再执行。**

### 5. 与其追着 DRC 报错修，不如按规格表全量审计
规格表是唯一真相。写脚本反查实际状态，一次性找出所有缺口。

### 6. 判断错误前先找反例
我凭「端口 10 间距太小」的猜测做扇出，把 33 个警告搞成 149 个。
**U7 也是 10 间距却从来没问题 —— 我该先问为什么。**

### 7. 桥有 30 秒超时
一次执行超过 ~30 个 API 调用会超时。
**响应超时 ≠ 脚本没跑完**，但每批控制在 4-5 个元件以内。
