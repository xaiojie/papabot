## 📘 官方规格书精读（2026-09-11）

**5 张官方规格书页已存档到 `datasheets/`**，以下是精读出的设计依据。

### PW7120 保护 IC（SOT23-6L，印字 `20CB 7120`）

| 脚 | 名称 | 功能 |
|---|---|---|
| 1 | **DOUT** | 放电控制输出，接放电 MOS（Q2）栅极 |
| 2 | **COUT** | 充电控制输出，接充电 MOS（Q1）栅极 |
| 3 | **VM** | 充/放电**电流检测**输入。经限流电阻（一般 1kΩ）接 Q1 源极，**检测电流在 Q1+Q2 两个 MOS 上形成的压降** |
| 4 | **VC** | 两节电池中间节点输入 |
| 5 | **VDD** | 电源输入（电池正极），**需 0.1µF 瓷片去耦** |
| 6 | **VSS** | 电源地（电池负极）|

**官方外围推荐值（原文抄录）**：

> R1 和 R2 用于稳定芯片的供电电压，**推荐分别使用 330Ω**。
> R1、R2 太大 → 导通电流导致检测电压上升，阈值偏差增大，充电器反接时 VDD-VSS 可能超极限；
> R1、R2 太小 → 反接时芯片损坏。**一般控制在 100Ω 至 470Ω 之间**。
>
> R3 太小 → 充电器反接时芯片内部流入过大电流有损坏危险；
> R3 太大 → 接高电压充电器时可能无法切断充电电流。**应控制在 1KΩ 至 4KΩ 之间**。
>
> C1 和 C2 **推荐 ≥ 0.1µF**。

**Q1/Q2 选型参考**：`PW8206A6S`（SOT23-6）、`PW4406A`（SOP8）、`PW20N03`/`PW50N03`（TO252）

**极限参数**：

| 项 | 范围 |
|---|---|
| 供电 VDD | −0.3 ~ **+12V** |
| VM / COUT 允许输入 | VDD−30 ~ VDD+0.3V |
| VC / DOUT 允许输入 | −0.3 ~ VDD+0.3V |
| 功耗 PD（TA=25°C，θJA=200°C/W）| **625 mW** |
| 焊接温度（10 秒）| 260°C |

### PW4584A 充电 IC（SOP8-EP）

**引脚表**（官方）：

| 脚 | 符号 | 说明 |
|---|---|---|
| 1 | VIN | 电源输入 |
| 2 | AGND | 数字模拟地 |
| 3 | LX | 内部功率 MOS 漏极输入端，外接功率电感和二极管 |
| 4 | VBS | 外接 BOOST 升压输出端 |
| 5 | BAT | 充电输出端 |
| 6 | **ICHG** | **充电电流控制端口，外部通过电阻与地相接，可设置充电电流** |
| 7 | NTC | 热敏电阻输入端 |
| 8 | STAT | 充电状态指示端口 |
| 9 | PGND | 功率地，**需大面积良好接地和散热** |

**官方典型应用电路元件值**（规格书 p1）：

```
VIN 5V ──┬── CIN 10µF ── GND
         ├── R1 1K ── LED ── GND        （电源指示）
         └── L1 4.7µH ── LX(3)
                          │
                       D1 = SS34（肖特基）── VBS(4) ── BAT(5) ── 电池
                       
  ICHG(6) ── RICHG 1K ── GND            ← 充电电流设定
  CF1 = 1nF（VIN 附近）
  COUT = 10µF + CF2 = 1nF（BAT 附近）
  C2 = 22nF   C3 = 22nF   C4 = 1nF
  NTC(7) 接热敏电阻
  STAT(8) 充电状态指示
  AGND(2) / PGND(9) ── GND
```

**关键电气参数**：
| 项 | 值 |
|---|---|
| 输入 | 3.6–6V，过压 6V 关闭充电，**VIN 耐压 30V** |
| 输出 | 8.4V / 1A |
| **开关频率** | **500kHz** |
| 效率 | 90%（异步升压）|
| 充电电流 | **外部电阻调节 0.5A–1A** |
| 内置 | 自适应环路、输入欠压/过压、输出过压/短路保护、NTC |
| 封装 | SOP8-EP |

**⭐ 官方 PCB 布局建议（原文抄录，必须遵守）**：

1. 输入、L1、D1、VBS 引脚、BAT 引脚与 GND 组成的**功率通路，采用短而宽的布线**
2. 输入电容 **CIN、CF1 尽量靠近 PW4584A 的 VIN 引脚**；**COUT 尽量靠近 BAT 引脚**
3. **电感 L1 和肖特基 D1 应该直接相连，连接短而粗；芯片、L1、D1 三者同一层，不过孔和跳线**
4. **LX 节点（L1、D1、LX 引脚连接处）尽量短，面积尽量少**，以减少干扰和 EMI —— **这个很关键**
5. **芯片底部散热片是功率地，需与地可靠焊接，多打过孔增加散热**

**充电指示灯参考电路**：`PW2602C + LED2(红) + LED1(绿)`
- 充电中：LED2 亮，LED1 灭
- 充满：LED2 灭，LED1 亮

> 来源：[PW4584A 规格书 p1/p2](datasheets)

## 三、分模块网络表

### 模块 1 · 电池输入与保护 ✅ 型号已定

**主芯片：HY2120-CB**（HYCON 宏康 / 平芯微 PWChip，SOT-23-6）

| 引脚 | 连到 | 说明 |
|---|---|---|
| 电池连接器 + | `VBAT_RAW+` | 接线端子 ≥10A |
| 电池连接器 − | `VBAT_RAW−` | |
| 平衡头中点 | `BM` | ⚠️ 用万用表确认，**不只看线色** |
| IC `VDD` | `VBAT_RAW+` **经 R1 330Ω** | R1 范围 100–470Ω |
| IC `VSS` | `VBAT_RAW−` | |
| IC `VC` | `BM` **经 R2 330Ω** | 中间节点检测 |
| IC `VM` | 双 MOS 中间点 **经 R3 1k–4kΩ** | 过流检测 |
| IC `COUT` → Q1 栅极 | N-MOS 1 | **充电控制** |
| IC `DOUT` → Q2 栅极 | N-MOS 2 | **放电控制** |
| C1 / C2 | 各 0.1µF，靠近 VDD / VSS | 去耦 |
| 双 N-MOS | **背靠背串在 `VBAT_RAW−` → `GND`** | 低端开关 |

**HY2120-CB 已核实的保护参数**（来源：平芯微官方文章 + 立创商城）：

| 项 | 值 |
|---|---|
| 过充检测 | **4.280V** ±25mV，延时 1.0s |
| 过充释放 | 4.080V，延时 ~16ms |
| **过放检测** | **2.900V** ±80mV，延时 128ms |
| 过放释放 | 3.000V，延时 ~1.2ms（**CB 版支持自恢复**）|
| 放电过流 | **VM 端 0.200V** ±30mV，延时 12ms |
| 充电过流 | VM 端 −0.200V，延时 8ms |
| **短路** | **0.6–1.4V**，响应 150–500µs |
| 工作/待机电流 | 4.5µA / 2.1µA |
| 0V 电池充电 | ✅ 支持 |

> ✅ **过充阈值 4.280V/节 = 8.56V，高于充电器的 8.40V 终止电压** —— 两者不冲突，
> 保护 IC 只在充电器失效时才动作。**这正是正确的架构。**

**过流点计算**（关键）：

```
I_过流 = 0.200V ÷ (两个 MOS 的 Rds(on) 之和)

目标过流点 ≈ 10A  →  Rds(on)总和应 ≈ 20mΩ  →  每个 MOS ≈ 10mΩ
```

⚠️ Rds(on) 随温度上升约 1.5 倍，**按 25°C 规格值选，热态过流点会更高**，这是可接受的。

**MOS 候选**（平芯微推荐）：
| 型号 | 封装 | 场景 |
|---|---|---|
| **PW8206A6S** | SOT-23-6（双 N-MOS）| 中小电流，占板小 |
| **PW4406A** | SOP8 | 通用 |
| PW20N03 / PW80N03 | TO252 | 大电流 |

> **备选方案**：不上主板，把 HX-2S-JH20 模块（46.7×23×3.15mm）放在电池旁边 —— 板面省 1074mm²。
> 实测下来这样板面最宽松（需高 70mm vs 72.8mm）。

### ⚠️ 选型修正：PW4252 **还没量产**

官方页面标「**生产 Q4**」，官方回复："目前Q4才会出，可以先看 PW4253"。

**而我们的电池只有 800mAh**：

| 型号 | 充电电流范围 | 对 800mAh 电池 | 状态 |
|---|---|---|---|
| PW4252 | 0.4–1.2A | 0.5–1.5C | ❌ Q4 才量产 |
| **PW4584A** ⭐ | **0.5–1A** | **0.63–1.25C** | ✅ **量产** |
| PW4253 | 1.1–2A | 1.4–2.5C ❌ **太快** | ✅ 量产 |

**结论：改用 PW4584A，充电电流设 0.5A**（约 0.63C，对 45C 动力芯是安全的）

**PW4584A 参数**（官方）：
- 输入 3.6–6V，**VIN 耐压 30V**，输入过压 6V 关闭
- 升压型，两串，充满 **8.4V**
- 充电电流 **0.5A–1A** 电阻可调
- **带 OVP 过压保护**
- **SOP8-EP**
- 官方评论确认：**可与 PW7052 组合**实现充电+保护；**脚位与 PW4053A 相同**

### 模块 5 · 舵机（PCA9685 裸芯片 + 8 路座）

#### 🔑 已核实的芯片特性（NXP 官方）

> "Sixteen **totem pole** outputs (sink 25 mA and **source 10 mA at 5 V**) with software programmable open-drain selection (**default at totem pole**)."

**→ 默认推挽输出，不需要外加上拉电阻。** 省掉 16 个电阻。

#### 连接

| 引脚 | 连到 | 说明 |
|---|---|---|
| `VDD` | `+3V3` | **3.3V**（I2C 也上拉到 3.3V）|
| `VSS` | `GND` | |
| `SDA` / `SCL` | `PCA_SDA` / `PCA_SCL` | 上拉 10kΩ 到 `+3V3` |
| `OE` | `PCA_OE_N` + 10kΩ 上拉到 `+3V3` | **高电平禁止输出** → 上电默认禁止，舵机不乱动 |
| `A0`–`A5` | `GND` | I2C 地址 0x40 |
| `EXTCLK` | 悬空 | 用内部 25MHz 振荡器 |
| `LED0`–`LED7` | `PWM0`–`PWM7` | → 8 个舵机信号脚 |
| `LED8`–`LED15` | 悬空（可留测试点）| 备用 8 路 |
| `VDD` 去耦 | 0.1µF + 10µF 到 GND | 紧贴芯片 |

#### 舵机 3P 座 ×8

```
每个 3P 座：
  1  信号  ← PCA9685 LEDn
  2  +5V   ← 【+5V_SERVO 铺铜，就近取】
  3  GND   ← 【GND 铺铜，就近取】
```

⚠️ **脚序必须和舵机线色对上**（红色电源在中间，地/信号在两旁，不同批次可能不同）——**焊接前用蜂鸣档确认**。

⚠️ **8A 全部走铺铜**，每个座就近从铺铜取电，**绝不串联**。

## 四、关键设计要点

| # | 要点 | 原因 |
|---|---|---|
| 1 | **PCA9685 的 VDD 接 3.3V，不是 5V** | I2C 上拉到 3.3V；ESP32 GPIO 不耐 5V |
| 2 | **舵机信号 3.3V 电平可用** | MG90S 输入高阈值约 2.4V ✓ |
| 3 | **OE 上拉到 3.3V = 上电禁止输出** | 舵机不乱动，固件初始化后才放开 |
| 4 | **PCA9685 输出不用上拉** | NXP 核实：默认推挽，10mA 源出 |
| 5 | **两路 5V 只共地，正极绝不并联** | 舵机噪声不窜进逻辑 |
| 6 | **8A 走 2oz 铺铜（≥4mm 宽）** | 不过细走线、不过单根排针 |
| 7 | **底层整片 GND 铺铜** | RevA 没有地平面，是硬伤 |
| 8 | **DFR0753 背面散热焊盘铺铜 + 打散热过孔** | 40W 满载发热大 |
| 9 | **电池采样从总开关后取** | 关机时读数为 0，能区分"关机"和"没电" |
| 10 | **充电走保护后的 P+/P−（共口）** | 过充时有保护板兜底 |

## 六、上电顺序

```
1. 不接电池，量各电源网络对 GND 不短路
2. 接电池（不插开发板），测 VBAT_PROT ≈ 电池电压
3. 总开关 ON，测 +5V_SERVO 和 +5V_LOGIC 都 ≈5.0V
4. 插开发板，测 +3V3 ≈3.3V，开机正常
5. 接屏幕 → 出画面
6. 接麦克风/功放 → 录音放音
7. 接 PCA9685（先不插舵机）→ 量 VDD=3.3V、OE 被上拉
8. 插 1 个舵机测小角度 → 记电流/压降/温升
9. 逐级 2 → 4 → 8 个
```
