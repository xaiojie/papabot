关于这一页

取帧流程：

浏览器 → GET /api/device/frame?screen=X
        → 服务器串口发 "stats off" / "screen X" / "dumpr"
        → 固件把帧缓冲做行程编码（RLE）后从串口发出
        → 服务器解码重建成 PNG 返回
为什么能实时：这些界面大部分是纯黑，行程编码（RLE）压掉 90% 以上 —— 整屏十六进制要 312 KB / 0.93 秒，RLE 只要 7–23 KB / 0.04 秒。
再把「重复下发 screen 命令」（每次触发 133 ms 全屏重绘）和「PNG 放大到 640×480」去掉之后， 端到端实测：表情 10 fps、时钟/天气/额度 29–32 fps，六屏平均 17.8 fps。
点「▶ 实时」开始连拍；切屏按钮会强制下发一次 screen 命令。
