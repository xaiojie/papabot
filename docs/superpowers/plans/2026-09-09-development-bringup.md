# 开发测试接线与固件实施记录

用户已授权执行接线图和测试程序两项。日期：2026-09-09。

## 范围

- 主控：立创 ESP32S3R8N8，8 MB Flash / 8 MB OPI PSRAM，电脑 USB 供电，CH340 UART0 控制台。
- 屏幕：TOUGLESY 2.4 寸 ST7789 + EC11，3.3 V 外部稳压供电，12 针与 RevB 一致；旋钮/按键保留在原板。
- 舵机：1 个 MG90S，外部 5 V 供电，GPIO18 临时直接 PWM。与最终 PCA9685 接法分开。
- 先主控，再屏幕与控件，再单舵机。按单通道可调电源分别测试，不假定电源通道数或实测电流。
- 不改 PCB/机械，不采购、不烧录硬件；完成本机编译和可运行的行为测试，实机结果留空。

## 实现方案

独立工程 `firmware/bringup`，PlatformIO espressif32 6.12.0 / Arduino-ESP32 2.0.17；Adafruit ST7789 驱动与商家示例一致。引脚 JSON 生成固件头文件、CSV、接线 SVG，核对 RevB 的原始接口表。固件通过串口命令选择被动、屏幕或单舵机模式，默认不初始化屏幕、不输出舵机 PWM。舵机显式启用后只允许 1400–1600 μs，后续变化限速，10 秒无有效控制命令停止输出；这不切断舵机电源。
