# DesktopAssistant A4 外壳与装配模型

2026-09-14。依据已确认的 A4 方案、2026-09-13 最新 BOM 与用户最新版 PCB 制作。此目录为 **CAD 试装版本**：有实际可编辑模型和独立 STL；尺寸未全部经过到货实测，尚未完成打印、承重、走路和温升试验。

## 打开与查看

- 原生文件：`DesktopAssistant-整机结构-A4.blend`，Blender 5.2.1 LTS。
- 主场景：`20_A4_COMPLETE_ASSEMBLY`。
- 内部主板：`21_A4_INTERNAL`；下层电池与降压：`22_A4_LOWER_DECK`。
- 爆炸图：`23_A4_EXPLODED`；拆前盖：`24_A4_FRONT_REMOVED`；打印件总览：`25_A4_PRINT_PARTS`。
- 完整 STL：`stl-complete/`，31 个文件，一文件一零件，各打印 1 件。
- 试配件：`coupons/`，5 个文件；T01–T04 是对应安装件原尺寸副本，不能缩放。
- `renders/` 中图片均由本目录 Blender 模型渲染。屏幕表情仅供外观展示，不代表固件已修改。

姿态控制对象为`JNT_FL_HIP_X`、`JNT_FL_KNEE_X`等，FR/RL/RR对应其余三腿；绕本地X轴调整。当前零位为本次检查的站姿，已测试的离散角度不是舵机允许的完整连续行程。

只打印零件清单中的对象。`REF__`、显示表情、灯光、相机及展示副本均不打印。原生文件用米作坐标、显示单位为毫米；STL 已转换为毫米，切片软件保持 **100%**，禁止再乘 1000。

## 本版修改

| 项目 | A4 实际模型 |
|---|---|
| 机身 | 94 × 132 × 76 mm；不含脚、耳、紧固件与外露插头 |
| 前脸 | 奶油白浅前框；取消旧深凹井、EC11 和按键结构 |
| 外窗 | 黑色可换遮边；57 × 42 × 0.8 mm 透明 PC 保护片，表面比前框低约 0.45 mm |
| 液晶 | HS24S010B 横屏，72.26 × 43 mm 标称背板；液晶玻璃在保护片后方，单独压框固定 |
| 主板 | 保持 110 × 75 × 1.6 mm，横向占宽 75，纵向 110；四孔左右67、前后102 mm |
| 主板定位 | 板底 Z=76.5；相对居中位置后移4 mm，为前屏接头留空间 |
| 电池 | 低位可换托盘，内净宽32.8、长61 mm；暂按 ACE800 的32×60×16包络 |
| 电源 | 两个开放绑带托架；取消旧外置充电板、PCA9685 和独立保护板专用架 |
| 四腿 | 八个MG90S保持原尺寸；重做固定座、上腿和下腿；四脚外沿宽174.9 mm |
| 维修 | 前盖、后盖、USB侧板、上壳分步可拆；主板和电池能按指定顺序取出 |

主板的模型坐标变换为 **X=v−37.5；Y=59−u**，其中 u、v 是 PCB 坐标表中的从左、从上距离。孔位为 X=±33.5，Y=−47、55。J6 USB参考位置为 (32.5,46)，J3屏幕接口为 (−31.5,−29)。

模型主板的顶面使用用户最新 Gerber 图片，保留“小皖子和爬爬 2026 0913设计”丝印。器件立体外形是按坐标建立的标称包络，不能当成供应商 STEP 模型。PCB、电气连接、原 A3、原 BOM 均未改动。

## 试配优先顺序

1. **T04 舵机固定座**：检查该批 MG90S 壳体、耳孔、原装舵盘和螺丝。槽孔允许小幅调节，不代表所有 MG90S 都通用。
2. **T01 屏幕压框、T02 黑色遮边**：检查72.26×43背板、玻璃边缘和实际亮区。压框用0.5 mm软垫接触背板四角，禁止压玻璃、元件或排线。
3. **T03 USB侧板**：用将来实际使用的线测试。CAD检查的插头护套为15×14×8，金属端为6.5×8.4×2.6 mm；超出包络的线不能沿用通过结论。
4. **T05 主板孔位框**：按实板四孔检查67×102中心距和支柱顶部接触位置。板上M2.5螺钉头外径≤5 mm，不加大直径金属垫片。
5. 完成上述配合，再打印底盘、主板架及其余外壳。T01–T04试配通过的成品可直接用于装机，不需要重复打印。

## 打印起始设置

建议0.4喷嘴、0.2层高。外观试配可用PLA，受力件优先用经过试打校准的PETG。外壳4道墙；L101/L102/L104和R05用6道墙、40–60%填充作为试制起点，不作为承重保证。

STL已按建议方向放到Z=0。前后框及壳体有悬空凸台，切片时检查支撑；R06倒置后仅有四个小接触点，必须检查裙边和支撑，不能直接沿用默认切片。舵机孔、螺母槽和盲孔内避免难以清理的支撑。自攻螺钉手拧，先用小件校准Ø1.7导孔，不用电批硬压。

透明保护片、EVA、束带、橡胶脚垫与电子件不包含在打印 STL 中。保护片为切割件，不应以普通不透明打印件替代。

## 装配顺序

1. 在无电状态试装八个舵机与原装舵盘，确认中位；打印件不含花键，不得用打印孔代替原装舵盘。
2. 四个L101固定到底盘；装上腿/膝舵机/下腿，装Ø12×2脚垫。紧固件不要碰舵机壳体、线口或转动件。
3. 安装R21电池托盘和R17/R18降压托架。电池用0.8 mm底垫和两条束带固定，端部开口走引线；NTC贴近电池，另固定线束。
4. 装R06主板支架，检查螺母已就位；再装主板。确认焊脚与下层模块、绑带、导线保持净空。
5. 装屏幕、保护片和背压框。CN1需要低矮插头或弯脚接线方案；模型预留的接头向后深度仅7.7 mm，常见长杜邦母头不能直接假定可用。
6. 后盖装喇叭、功放和开关接口板。未定型号通过更换R08/R11/R14/R17等小件调整，不能强行塞入预留框。
7. 先整理线束，再装上壳、前后盖和USB侧板。电源线沿侧边固定；麦克风线与舵机电源线分开；屏幕线和主板前部8路舵机插头上方留弯线空间。
8. 主板端子拧线、保险丝插拔、ESP32下载/拔出在开壳状态操作。开关是装配后可从后部操作的总开关候选件；内部没有EC11或日常控制按钮。

## 拆装路径与限制

- 断电、断开电池后，先卸USB侧板，再断开前后盖线束并移除前后组件；之后上壳沿+Z取出。
- 主板拔线并卸四颗固定螺钉后沿+Z取出。
- 更换R21电池托盘需要先取出主板与R06支架；它可独立更换，但本版不是免开壳抽拉式电池仓。
- 爆炸图为零件分组示意，各组展示位移不等同于可同时运动的拆卸路径。请按上述顺序操作。
- 离散几何检查不覆盖软线、手指、螺丝刀全包络、动态地面接触及连续运动。

## 仍需实物核实的输入

- HS24S010B PDF 的规格表和机械图存在型号标题、VA/AA差异。采用可换压框及遮边；收到屏幕后以实际亮区、背板、接头复核。透明PC保护片是本版新增结构辅料，未采购。
- J6采购件C165948 / TYPE-C-31-M-12与当前PCB库封装的完整机械兼容尚未证明。侧板通过的是明确尺寸的插头量规；不能由此证明焊盘兼容。
- ACE800目前只是60×32×16标称包络；更换电池型号时需改托盘。电池引线、T插转XT30和均衡线仍要实配。
- DFR0753、麦克风、喇叭及后部开关存在预留或候选尺寸；需要实际产品才能定稿。功放端子、ESP32插合总高也应复核。
- 质量与支撑投影估算使用了公开标称和明确假设，详见报告；未做承重、扭矩、步态、热、声学、续航或跌落测试。
