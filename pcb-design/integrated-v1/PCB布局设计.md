## 一、层叠与工艺

```
┌─────────────── 顶层（Top）───────────────┐
│  信号走线 + 【+5V_SERVO 铺铜】+ 元件      │
│  + 局部 GND 铺铜填充                      │
├─────────────── 底层（Bottom）─────────────┤
│  【整片 GND 铺铜】← RevA 的教训，必须做    │
│  + 少量跨接走线                           │

```

| 项 | 值 | 理由 |
|---|---|---|
| 层数 | **2 层** | 成本 |
| 铜厚 | **2oz（70µm）** | 8A 需要 |
| 板厚 | 1.6mm | 标准 |
| 最小线宽/间距 | 6/6 mil | 嘉立创常规 |
| 最小过孔 | 0.3/0.6 mm | |
| 表面处理 | 沉金（ENIG）| 细间距 IC 好焊 |

## 二、分区布局

```
┌────────────────────── 110 mm ──────────────────────┐
│  ┌── 电源区（左上，约占 60×40）──┐ ┌── 主控区 ──┐ │
│  │  电池端子 · 保险丝 · 开关      │ │            │ │
│  │  保护 IC + 双MOS + 均衡×2     │ │  ESP32     │ │
│  │  PW4584A 充电 + Type-C        │ │  2×20 插座 │ │
│  │  DFR0753 (5V/8A)              │ │  (20.5×52) │ │
│  │  逻辑降压 (5V/3A)             │ │            │ │
│  │  1000µF / 470µF               │ │  EC11      │ │
│  └───────────────────────────────┘ └────────────┘ │
│  ┌── 舵机区（中下）──────────────┐ ┌── 音频区 ─┐ │
│  │  PCA9685 芯片 + 8×3P 座       │ │ 麦克风    │ │
│  │  ← +5V_SERVO 铺铜在这里分配   │ │ 功放      │ │
│  └───────────────────────────────┘ └───────────┘ │
│  ┌── 显示接口（下边）─┐                           │
│  │  屏幕排针 8/14P     │                           │
│  └─────────────────────┘                           │
└─────────────────────────────────────────────────────┘
```

### 摆放原则

| # | 原则 | 原因 |
|---|---|---|
| 1 | **电池 → 保险丝 → 开关 → 两路降压 单向排列** | 走线短，回路面积小 |
| 2 | **DFR0753 紧贴 8 路舵机座** | 5V 路径最短，压降最小 |
| 3 | **逻辑降压紧贴开发板 5V 针** | 逻辑 5V 走线短 |
| 4 | **ESP32 居中** | 到 PCA9685(I2C)、麦克风/功放(I2S)、屏幕(SPI) 都短 |
| 5 | **大电流区与信号区物理分开** | 舵机噪声不窜进 I2S/SPI |
| 6 | **Type-C 靠板边** | 便于插线 |
| 7 | **EC11 位置由前面板决定** | 需和结构件对齐 |
| 8 | **屏幕排针靠板边** | 排线最短 |

## 三、铺铜策略（最关键）

### 3.1 +5V_SERVO 舵机铺铜

```
DFR0753 VOUT ──┬── 1000µF ── GND
               │
        【5V 铺铜，顶层】
               │
    ┌──────┬───┴───┬──────┬──────┐
  舵机1  舵机2  ...  舵机7  舵机8
```

| 要求 | 值 |
|---|---|
| **宽度** | **≥4 mm**（2oz 铜，8A，温升 10°C）|
| 拓扑 | **树形分配**，绝不串联 |
| 每路分支 | ≥1 mm（单舵机峰值 1A）|
| 去耦 | 每个舵机座旁可选 100µF（共 3–4 个足够）|

### 3.2 底层 GND 整片铺铜

**这是 RevA 的硬伤** —— 仓库里明确记着 RevA「没有铺铜地平面」。

| 要求 | 说明 |
|---|---|
| 底层除必要跨线外**整片 GND** | 提供低阻抗回流路径 |
| 顶层也补 GND 填充 | 提高耦合，减少环路 |
| **舵机大电流回路要短** | 5V 去 → 舵机 → GND 回，回路面积越小越好 |

### 3.3 两路 5V 的隔离

```
+5V_SERVO  ──┐
             ├── 只共地，【正极绝不并联】
+5V_LOGIC  ──┘
```

- 两条铺铜**物理分开**，中间留 GND 隔离带
- 逻辑 5V 的铺铜**不要伸进舵机区**

## 四、散热设计

### 4.1 DFR0753（40W 满载）

| 措施 | 说明 |
|---|---|
| **背面散热焊盘铺铜** | 官方明确要求 |
| **打 6–9 个 Ø0.3mm 散热过孔** | 连到底层 GND 铺铜 |
| 顶层散热焊盘面积 | ≥100 mm² |
| 远离温度敏感器件 | 尤其远离麦克风和晶振 |

### 4.2 PW4584A（SOP8-EP）

| 措施 | 说明 |
|---|---|
| **底部散热焊盘必须焊 + 铺铜** | 否则过热降流 |
| 打 4–6 个散热过孔 | 到底层 GND |
| 电感 L（3.3µH）远离麦克风 | 开关噪声 |

### 4.3 双 N-MOS（PW4406A ×2）

| 措施 | 说明 |
|---|---|
| 8A 时导通损耗 = I²R = 8² × 0.0286 ≈ **1.8W** | 需要铺铜散热 |
| 两个 SOP8 的散热焊盘都铺铜 | |

## 五、关键走线规则

| 网络 | 要求 | 原因 |
|---|---|---|
| **+5V_SERVO** | ≥4mm 铺铜 | 8A |
| **电池主电流（P+ / P−）** | ≥4mm 铺铜，或 2mm 宽走线 | 10A |
| **GND 回流** | 底层整片铺铜 | 低阻抗 |
| **I2S（MIC/AMP）** | 尽量短，远离 5V 铺铜 | 时钟串扰 |
| **SPI（屏幕）** | ≤10MHz，等长不要求，但**SCLK 要短** | 时序 |
| **I2C（PCA/充电）** | 短，上拉到 3.3V | 100kHz 够慢，但电容要小 |
| **PWM0–7** | 从 PCA9685 到舵机座尽量短 | 抗干扰 |
| **ADC_BAT** | 远离开关节点，加 100nF | 采样精度 |
| **充电 SW 节点** | **面积最小**（高 di/dt）| EMI |

## 六、可借用官方参考设计的部分

**官方 Code 15 参考板（35 × 21mm）**已经验证了「PW7120 + PW4406A×2 + PW4584A」的布局。

我们要**照抄的部分**：

| 部分 | 照抄程度 |
|---|---|
| PW7120 外围（R1/R2/R3/C1/C2）| ✅ **完全照抄** |
| PW4406A ×2 背靠背 + VM 走线 | ✅ **完全照抄**（这是过流检测的关键）|
| PW4584A 外围（D1/L/RADJ/电容）| ✅ **完全照抄** |
| Type-C + CC 电阻 | ✅ **完全照抄** |
| 我们**新增** | 均衡 ×2、DFR0753、逻辑降压、PCA9685、8 舵机座、主控插座、音频、显示 |

**⚠️ 特别注意**：PW4406A 的**背靠背连接和 VM 走线必须严格照抄** ——
过流检测靠的是 MOS 内阻上的压降，走线不对称会导致检测偏差。

## 七、装配注意

| 项 | 说明 |
|---|---|
| **先焊矮件再焊高件** | 电阻/电容 → IC → 插座 → 模块 |
| **SOP8-EP 的散热焊盘** | 需要热风枪或底部加热，手焊要用大量助焊剂 |
| **Type-C 母座** | 细间距，用拖焊 + 吸锡带 |
| **双 N-MOS 位置** | 大电流，焊点要饱满 |
| **DFR0753** | 散热焊盘必须焊实 |

## 八、DRC 检查清单

```
□ 最小线宽/间距 ≥ 6/6 mil
□ +5V_SERVO 铺铜宽度 ≥ 4mm（用铺铜宽度测量工具核）
□ 底层 GND 铺铜无孤立铜（孤岛要删）
□ 所有 GND 网络连通（无单点连接）
□ DFR0753 / PW4584A / PW4406A 散热焊盘有过孔
□ 两路 5V 铺铜间距 ≥ 2mm（隔离）
□ 板边距铜 ≥ 0.3mm
□ 安装孔周围 1mm 内无铜
□ 无未连接网络（飞线）
□ 丝印不压焊盘
```
