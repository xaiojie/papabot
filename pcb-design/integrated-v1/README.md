## 四、电源架构

```
2S 电池 (7.4V, 满 8.4V)
   │
   ├─ 主正极 ──→ 保护 IC ──┬── 充电 IC ← Type-C 5V
   ├─ 主负极 ──→  (B+/B−)  │
   └─ 平衡头 ──→   (BM)    │
                           │
                    受保护 P+ / P−
                           │
                     [保险丝 7.5A]
                           │
                     [S1A 总开关]
                           │
              ┌────────────┴────────────┐
              │                         │
        [DFR0753 5V/8A]          [逻辑 5V 降压 3A]
              │                         │
        ┌─────┴─────┐                   │
        │ 5V 铺铜   │                   │
        │ 2oz, ≥4mm │                   │
        └─────┬─────┘                   │
              │                         │
        8× 3P 舵机座              开发板 5V 针 → 3.3V
        (VCC/GND 就近取铺铜)             │
              ↑                    ESP32 / 屏幕 / 麦克风
              │                         │
        PCA9685 的 8 路 PWM ────────────┘
       （PCA9685 只出信号；VCC=3.3V）
```

### 🔴 三条铁律（沿用）

1. **两路 5V 只共地，正极绝不并联**
2. **舵机总电流走 2oz 铺铜，不过细走线/单根排针**
3. **USB 与电池供电不能同时上**（除非加防倒灌）

## 十、板框定稿：110 × 75 mm（2026-09-11 更新）

### 🔴 装箱计算推翻了「PCA9685 用模块」这个决策

用 skyline 左下装箱算法（元件间留 2mm），按真实尺寸算：

| 方案 | 板宽 100 | 板宽 110 | 板宽 115 |
|---|---|---|---|
| **A. PCA9685 用现成模块**（62.5×25.5）| 需高 **96.3mm** ❌ | 需高 83.0mm ⚠️ | 需高 79.5mm ⚠️ |
| **B. PCA9685 裸芯片 + 板上 8 路舵机座** | 需高 80.0mm | **需高 72.8mm** ✅ | 需高 71.0mm |

**原定的 100 × 75mm 在方案 A 下根本装不下**（需要 96.3mm 高）。

**原因**：PCA9685 模块一块占 **1594 mm²**，是整板面积的 **18%** —— 最大的空间黑洞。
换成裸芯片（TSSOP-28，约 104 mm²）+ 板上 8 路 3P 舵机座（约 264 mm²），合计约 400 mm²，
**省下约 1190 mm²**。

### ✅ 定稿

```
板框：110 × 75 mm
层数：2 层
铜厚：2oz
填充率：65.6%（舒适区）
```

比原计划宽 10mm。外壳内腔约 **124 × 96.8mm**，放得下。

### 决策变更

| # | 原决策 | 新决策 | 原因 |
|---|---|---|---|
| 5 | PCA9685 **用模块** | ⚠️ **改成裸芯片 TSSOP-28 + 板上 8 路舵机座** | 空间不够；而且自己配电对 8A 更可控 |

> **保留「用模块」的另一个理由也消失了**：原本担心自己画 PCA9685 外围麻烦，
> 但它其实只需要**芯片 + 10µF 去耦 + I2C 上拉 + OE 上拉**，很简单。
> 而且**自己配电反而更好** —— 模块的 V+ 铜箔能不能扛 8A 一直是个未知数。

## 十一、原理图设计（2026-09-11）

见 [原理图设计.md](原理图设计.md) —— 网络表 + 设计要点，可直接照着画。

### 本轮核实的一个关键细节

**PCA9685 裸芯片的输出是推挽还是开漏？** 决定要不要加 16 个上拉电阻。

NXP 官方原文：

> Sixteen **totem pole** outputs (sink 25 mA and **source 10 mA at 5 V**)
> with software programmable open-drain LED outputs selection (**default at totem pole**).

**结论**：
- **默认推挽，不需要外加上拉** → 省掉 16 个电阻
- 源出 10mA 足够驱动舵机信号（高阻输入）
- 输出电平 = VDD → **VDD 接 3.3V，舵机信号就是 3.3V**，MG90S 输入阈值约 2.4V，识别得了 ✓

### 保护方案的板面代价

## 十二、电源方案定稿（2026-09-11 第二轮）

### 拿到平芯微官方的「保护+充电二合一」参考设计

平芯微官方技术文章给出的方案，**架构和我们完全一致**：
`PW7120 保护 + PW4406A×2 MOS + PW4252 升压充电`

**官方参考原理图与元件值已抄录**，见
[电源官方参考原理图.png](电源官方参考原理图.png) / [电源官方参考PCB.png](电源官方参考PCB.png)
（原文：https://www.pwchip.com/tw/product/632.html）

### 最终选型

| 功能 | 型号 | 封装 | 立创 | 其它渠道 |
|---|---|---|---|---|
| **2S 保护** | **PW7120** 或 **HY2120-CB** | SOT23-6L | HY2120 = ✅ C168776 | PW7120 = icinz.com |
| **均衡 ×2** | **PW2213** 或 **HY2213** | SOT23-6L | HY2213 = ✅ C168784 | — |
| **升压充电** | **PW4584A**（不是 PW4252）| SOP8-EP | ❌ | icinz.com / 淘宝 |
| **双 N-MOS** | **PW4406A** ×2 | SOP8 | ❌ | 同上 |

**关键参数**（PW7120 / HY2120-CB 两者相同）：
```
过充 4.28V/节 = 8.56V   ← 高于充电器 8.40V 终止电压，不冲突
过放 2.90V/节 = 5.80V
过流 = 0.200V ÷ MOS 内阻之和   ← 官方确认"不是合金电阻，是检测电压和MOS内阻"
```

### 两处修正

1. **PW4252 还没量产**（官方标"生产 Q4"）→ 改用 **PW4584A**（量产，0.5–1A 可调）
   - 我们的电池只有 800mAh，PW4253 的 1.1–2A 太快（1.4–2.5C）
   - **PW4584A 设 0.5A**（0.63C，对 45C 动力芯安全）

2. **PW7120 立创搜不到**（官方回复要去 icinz.com 买）
   - 但宏康的 **HY2120-CB（C168776）/ HY2213（C168784）立创有货**
   - **两方案电路拓扑相同**（阈值 4.28V/2.9V 完全一致）
   - **建议：用官方原理图做设计蓝本，按立创能买齐的方案采购**

### 过流保护点的一个注意

官方参考设计（PW4406A ×2）的过流点是 **约 7A**，而 8 个 MG90S 的理论峰值是 6–8A。

**这意味着：8 个舵机同时堵转时会触发保护。** 这是**可接受的**（同时堵转是异常工况），
但要在实测时确认正常行走/起身不会误触发。若要提高过流点，需换 **更低 Rds(on)** 的 MOS。

## 七、风险登记

| 风险 | 影响 | 缓解 |
|---|---|---|
| **8A 铺铜设计不当** | 发热/压降 → 舵机抽风、主控复位 | 2oz + ≥4mm + 底层 GND 面；打样后实测温升 |
| **2S 保护 IC 参数算错** | 过流误动作或保护失效 | 先用现成保护板对照实测，再画 IC 版 |
| **充电 IC 选型错误** | 充不进 / 充坏电池 | 确认**内置升压**（5V→8.4V） |
| **一次集成太多** | 首版失败概率高 | 分阶段：先电源+外设，PCA 用模块 |
| **模块尺寸不准** | 封装放不下 | 尺寸以实物为准，**收到货先量再定封装** |
| **结构件不同步** | 装不进外壳 | 板框定稿后同步改 Blender |
