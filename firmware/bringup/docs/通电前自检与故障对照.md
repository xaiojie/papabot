# 通电前自检与故障对照

本文是[开发测试接线与验收](开发测试接线与验收.md)的**前置安全层**。接线与验收说明回答“按什么顺序测”，本文回答“**在给任何一处上电之前，必须先用万用表排除什么**”，以及“出问题时先查哪里”。

状态：2026-09-10 编写。**本文全部为通电前检查方法，没有任何实测数据**，所有“实测结果”栏仍待到货后填写。

> 本工程没有硬件掉电隔离，也没有电源检测。烧坏的风险由**接线正确性**和**上电顺序**承担，不由软件承担。

---

## 0. 硬前提

- 可调稳压 + **限流**直流电源（能稳定输出 3.3 V 和 5.0 V）
- 万用表（通断/电阻档 + 直流电压档）
- 电烙铁、焊锡；2.54 mm 1×20P 公排针 ×2、1×12P 公排针 ×1
- 母对母杜邦线（10–20 cm）、舵机用公头转接
- USB **数据**线

## 1. 绝对红线

这四条一旦违反，可能是不可逆损坏，不是“配置问题”：

1. **屏幕 VCC 和 BLK 只能接 3.3 V。** RevA 时代是 5 V，旧习惯必须丢掉。当前电气版本是 RevB，屏幕走独立 `LCD_3V3`。
2. **屏幕不允许单独带电。** 控件上拉接在屏幕 VCC 上，屏幕带电而主控 USB 断开时可能经信号线给未供电的主控倒灌。改线一律全断电。
3. **任何接线动作前，USB 和外部电源都必须断开。** 不允许带电插拔杜邦线。
4. **不要让外部 3.3 V 正极接到开发板的 3V3 或 5V 排针。** 外部 3.3 V 只供屏幕模块，两边各自供电、只共地。

## 2. 断电状态：五项电学自检

**顺序不能跳过。** 全部在 USB 拔掉、外部电源输出关闭的状态下做。

| # | 检查 | 方法 | 合格判据 |
|---|---|---|---|
| A1 | 目视焊接 | 放大看排针每一针：虚焊、连锡、锡渣、针歪 | 每针独立、无跨针锡桥 |
| A2 | 电源对地短路 | 万用表电阻/通断档，量屏幕模块 **VCC ↔ GND** | **不导通**（不蜂鸣）；低阻值即先查短路 |
| A3 | 杜邦线单根通断 | 每根线两端对插，量首尾 | 导通；捏住线身晃动时不断续 |
| A4 | 相邻针不导通 | 万用表逐对量相邻排针 | 不导通（GND 组除外，见 A5） |
| A5 | 共地一致性 | 量屏幕 GND、开发板 GND、外部电源负极三者之间 | 全部导通，视为同一节点 |

**A2 是最关键的一项。** 屏幕模块上 VCC/GND 相邻，焊 12 针时最容易搭锡。若 A2 导通，不要上电，先清锡重查。

### 12 针方向怎么定

**以实物丝印为准，不要凭本文的“针号 1–12”猜朝向。** 本文和 CSV 的针号是**功能序号**，不承诺与实物排针的物理顺序、起脚方向一致。

实物识别方法（断电状态）：

1. 找模块排针旁的丝印（`GND` / `VCC` / `SCL` / `SDA` / `BLK` 等）。有丝印就以丝印为准，逐根对照[12 针接线表](屏幕12针接线表.csv)。
2. 丝印不清时，用万用表通断档找 **GND**：从排针各脚依次量到模块上大面积覆铜地、或屏幕金属屏蔽罩/固定孔地。对地导通的那一针就是 GND。
3. GND 确定后，**相邻脚通常是 VCC**（本类模块的常规排布），仍须用丝印或后续实测确认，**不要只凭相邻关系直接上电**。
4. 确认结果后，**把实物朝向画下来或拍照存档**，再焊排针。焊接时不要插 USB、电源或舵机。

> 若实物丝印顺序与 12 针表的功能序号冲突，**以实物为准**，并回报修改 `wiring.json`，不要反过来改接线去迁就文档。

## 3. 电源空载复测

每一项上电前都要做，重复三次也不为过：

1. 电源**空载**（不接任何负载）调到目标电压。
2. 万用表直流电压档复测输出端实际值，记录。
3. **关闭输出**，再接负载。
4. 首次排错可先设限流约 0.1 A（屏幕）/ 约 0.5 A（舵机空载）。**这是起始保护值，不是已测得的模块耗电或额定电流。**

目标值：屏幕支路 **3.3 V**，舵机支路 **5.0 V**。舵机支路建议电源在 5 V 时至少有 1 A、最好 2 A 余量（准备建议，非实测需求）。

## 4. 上电顺序

| 阶段 | 上电 | 断电 |
|---|---|---|
| 主控单独 | 接 USB | 拔 USB |
| 屏幕（外部 3.3 V） | **USB 先上**，确认固件处于 `PASSIVE`，再开外部 3.3 V | **先关外部 3.3 V，再拔 USB** |

背光在关外部电源前仍亮是**预期现象**，不是故障。

## 5. 故障对照表

### 主控阶段

| 症状 | 先查 | 动作 |
|---|---|---|
| 串口列表里没有设备 | 数据线是否只充电、CH340 驱动、USB 权限 | 换数据线；确认出现 `/dev/cu.wchusbserial*` 或 `/dev/cu.usbserial*`。该板可能同时出现原生 USB 串口，**不要凭列表顺序选** |
| 烧录停在连接阶段 | 未进入下载模式 | 按住 BOOT → 按一下 RESET → 松开 BOOT，重试。烧完按 RESET 正常启动，**不要一直按住 BOOT** |
| 反复复位重启 | 板卡型号或 PSRAM 配置不符 | 核对是否确为 N8R8；`qio_opi` 与 `BOARD_HAS_PSRAM` 已在编译参数中核对 |
| `selftest` 显示 PSRAM = 0 | 同上 | 先确认同款板；PSRAM 配置已在编译期核对，实机仍为 0 则回报 |
| 串口无 `READY / PASSIVE` | 波特率、发送换行设置 | 115200；串口发送设为换行或 CRLF |
| `wifi scan` 结果为 0 | 天线、环境、2.4 GHz 可用性 | **不足以单独判定故障**，记录数量即可 |
| LED 无短闪 | 板卡 LED 定义 | LED 在 GPIO48 且低有效 |

### 屏幕阶段

| 症状 | 先查 | 动作 |
|---|---|---|
| **整屏纯白、有背光，串口仍显示 `mode=PASSIVE`** | **固件从未初始化屏幕**（BLK 接 3.3 V 常亮，面板上了电但没有收到任何初始化命令，像素驱动未启动，肉眼就是白屏） | **这是预期状态，不是故障。** 发 `screen start` 后再看 |
| 完全无背光、全黑 | BLK / VCC 是否接上、极性是否反 | 断电复查；BLK 固定接 3.3 V |
| 只有背光、无图像 | CS / DC / RES / SCL / SDA、共地 | 逐根核对。**没有 MISO，串口显示 `SCREEN active` 只表示初始化命令已发出，不证明屏幕正常** |
| 电源进入恒流 CC、电压明显掉下来 | 短路 | **立即断电**，回到 A2 重查 |
| 图像倒置 | 方向设置 | 比较 `screen rotation 1` 与 `3`（默认 3） |
| 黑白反相 | 反色设置 | 比较 `screen invert 0` 与 `1`（**默认 0**，见 `board_config.h` 的 `SCREEN_INVERTED`） |
| 颜色次序仍错 | 驱动或模块批次 | **记录照片和模块批次**；反色设置不是所有颜色问题的修复手段 |
| 花屏 / 噪点 | SPI 速率、线长、接触 | SPI 已设 10 MHz；缩短杜邦线、重插 |
| 编码器转一格跳多格 | 每格合法相位跃迁数 | 比较 `encoder divisor 2` 与 `4`（默认 4）；记录最终值与方向 |
| 编码器方向相反 | 计数方向 | 记录，属可改的软件符号问题，不算硬件故障 |
| 按钮按一次跳多次 | 抖动 | 模块自带 10 k 上拉，固件不另开内部上拉；固件已有消抖，仍跳则查接线与接触 |
| PUSH / KEY0 完全无反应 | GPIO 接错 | PUSH=GPIO38、KEY0=GPIO40；核对开发板位置 R13 / R11 |

### 舵机阶段

| 症状 | 先查 | 动作 |
|---|---|---|
| `servo arm` 后猛转一下 | 首次回中位 | **预期现象**，前提是已卸下舵盘和腿、本体固定 |
| 持续抖动 / 嗡嗡响 | 堵转、脉宽越界、电源能力不足 | 先关 5 V；核对脉宽在 1000–2000 μs |
| 异常发热 | 堵转或过压 | **立即关 5 V 电源** |
| 完全不动 | 信号线、是否已 `arm`、5 V 是否开 | 核对 S/正/负三线定义，**不要只靠颜色** |
| 电源限流指示灯亮 / 电压塌陷 | 限流设太低、接线压降、堵转 | 先查接线与压降，再决定限流是否合理 |
| 回中位方向与预期相反 | 舵机安装方向 | 记录；装配阶段按反向处理 |
| 10 秒后停住 | PWM 超时 | 预期：无有效 `pulse` 命令 10 秒停发 PWM。**停 PWM 不等于断电**，舵机可能保持位置 |
| `status` 或错误命令后仍超时停住 | — | 预期：`status` 与无效参数不续时 |

## 7. 检查到什么程度才算完

三项（主控 / 屏幕 / 单舵机）通过后，**只证明这三件模块能通**。以下仍然**未验证**：

- 屏幕全亮最大电流、主控稳压余量与温升 → 直接影响 RevB 的 JP3 能否短接
- 八舵机同时动作的电源、压降、发热
- 整机承重、步态、结构配合、线束、声学
- 电池充电电流（TELESKY 板实际限流仍未知，不得套用标题 5 V/2 A）
- 语音、中文 UI、表情、步态等整机固件

不要用单舵机空载通过去推断八舵机电源通过。
