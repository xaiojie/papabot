A5 报告记录机身 124 × 112 × 76 mm，中立站姿含脚垫和耳朵为 162.9 × 116.5 × 122.46 mm。完整圆角效果图表达下一版方向，不能直接当作已修改的 A5 模型。

Git 跟踪 STL、建模脚本、渲染、说明和检查报告。原生 `.blend`、自动备份及重复整机 ZIP 沿用既有忽略规则保留本地；外部克隆需要原生模型时应另外取得对应文件。CAD 检查不替代实物打印、试装、承重或行走验证。
