## 推荐工作顺序

1. **建立元件尺寸与安装空间模型。** 先放入已选的整块屏幕模块、右侧旋钮、接插件和走线空间。舵机、主控、音频与供电模块尚未定型时，用显式标记的占位体；逐步用具体型号尺寸替换。模块内部元件只需达到外形和干涉检查所需精度。
2. **建立由独立零件组成的整机装配模型。** 前盖、主壳、底盖、屏幕支架、耳饰、腿部支架从一开始就分件，组装后渲染。壳体尺寸、屏幕位置和接口等用数值参数维护，避免先做一个整块外观实体再切分。
3. **完成外观渲染与拆装预览。** 使用已定配色，提供正面、侧面、背面、三分之四视角；展示拆前盖、拆底盖、爆炸图及内部空间。此阶段服务于比例和结构方案评审，未确认的尺寸会继续修改。
4. **细化结构与验证。** 定义壁厚、加强筋、安装柱、螺钉/螺母固定、工具进入空间、线束弯折空间和腿部运动避让。精确开窗、孔位与装配间隙按元件实测、选定打印工艺和供应商能力确定。
5. **关键小件先试配。** 优先输出屏幕定位/开窗样框、前盖连接样件和单腿舵机支架；需要的间隙样件随工艺一起打样。确认后再完善完整壳体，减少整套返工。
6. **输出正式打印交付包。** 各零件独立导出，检查封闭网格、相交面、法线、最小壁厚与实际导出尺寸，并在切片软件中检查。打印准备合格并不等于已完成实物装配与步态验证。

## 组件划分建议

| 组件 | 功能与拆装方向 | 配色方向 |
| --- | --- | --- |
| 可拆前盖 | 居中显示开窗、浅保护边；控件推荐移至后部，需核实拆焊条件 | 奶油白 |
| 前脸细边/装饰圈 | 依最小可打印宽度决定独立嵌件、与前盖一体或后处理着色 | 薄荷绿 |
| 主壳 | 固定前后结构并承载外观，尽量让维修从底部进入 | 奶油白 |
| 底盖/底盘 | 主控及后续 PCB 的可更换安装区域、线束整理、维修入口 | 奶油白 |
| 显示模块支架 | 固定完整的 91×44 mm 标称 PCB，并让左侧显示区对准机身中心 | 内部件，颜色次要 |
| 左右耳饰 | 用内部可拆固定避开麦克风、前盖接缝；不作为受力把手 | 薄荷绿外框，奶白内片 |
| 舵机支架与腿 | 按最终舵机孔位、舵盘、转轴和运动范围建立独立组件 | 薄荷绿；结构选材单独验证 |
| 脚垫 | 作为独立软质/外购件处理 | 黑色 |

首版优先研究定位结构配合螺钉的可拆方式，前盖/底盖连接避免把反复维护完全依赖于薄卡扣；具体紧固件规格待壁厚和受力评估后确定。不要把图上所有分色面都强制变成薄小打印件。

## 当前尺寸依据与未确定项

- 已选屏幕：TOUGLESY / 途格斯 2.4 英寸 TFT + EC11，ST7789、320×240、SPI、无触摸。
- 商品标称 PCB 91×44 mm、Ø3 mm 安装孔、孔中心距 84.5×37.5 mm，可作为初始模型参数，需确认实物公差。
- 商品所写屏幕 59×42.5 mm 与 2.4 英寸标称存在口径冲突，不能直接当最终可视开窗；须核实有效显示区、玻璃外形及相对 PCB 的位置。
- 旋钮总高度、模块背面最高元件、排针焊接方向和线缆插拔空间尚未确认。15 mm 轴长不代表模块完整厚度。
- V6 的约 118 mm 外宽基于假设偏置计算，不是已实测的冻结尺寸；腿、重心和内部体积也会影响比例。
- 舵机已选定 [MG90S 全金属齿轮 180 度](../../../servo-mg90s-180.md)，整机 8 个；该店实物外形、孔距、舵盘和承载待核实，assembly-v1 仍保留旧占位体。
- 主控、音频模块、供电及定制 PCB 的板形孔位尚未定型；可以先做占位布局，但最终固定孔不应凭空确定。

## 软件与文件

已通过本机命令验证安装 **Blender 5.2.1 LTS**，路径 /Applications/Blender.app。Blender 可以管理分件装配、材质、渲染及 STL 导出；可用打印检查工具辅助发现网格问题。商家实际接受的格式仍应按其要求交付。[Blender 官方打印工具说明](https://extensions.blender.org/add-ons/print3d-toolbox/)

如果后续需要频繁改动精密孔位、尺寸关联和 STEP 工程交换，可以用 FreeCAD 等参数化 CAD 维护对应结构，再导入 Blender 统一渲染。这是工程工具补充建议，并非当前已经安装或建立 CAD 项目。[FreeCAD 官方功能说明](https://www.freecad.org/features.php)

| 最终计划文件 | 用途 |
| --- | --- |
| desktop-assistant-assembly.blend | 可编辑总装，各部件独立，包含场景、材质和相机 |
| renders/*.png | 整机各视角、爆炸图、拆装示意 |
| parts/*.stl | 每个可打印部件一个文件，毫米尺寸交付并复核；不包含现成电子元件 |
| print-specification.pdf 或 .md | 部件编号、数量、颜色、材料/表面要求、关键尺寸与安装说明 |
| hardware-list.csv | 紧固件、脚垫等非打印配件清单，避免打印件与外购件混淆 |
| validation-report.md | 导出尺寸、网格、切片及已完成/未完成的试配记录 |

STL 打印件与渲染材质分开交付：颜色需要在零件清单和参考图里明确。3MF 可在确认商家切片流程后按需另行准备；STEP 仅在确有 CAD 源模型时导出，不把普通三角网格包装成可参数编辑的工程实体。G-code 留给确定打印机和工艺后的切片流程。

## 第一阶段建议交付范围

先做 **含内部占位件、分件组织和已定配色的 Blender 整机模型**，附渲染、基本拆装/爆炸视图和待补尺寸表。这个阶段完成后再逐个把各部件完善为可试配打印版本，最后发布经检查的完整商家交付包。
