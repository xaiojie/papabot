# 网页控制舵机 · 命令表

> 打开 https://papa.papaclaoud.top/ → 登录 → 拉到最下面**终端**输入框
> 敲命令回车即可

---

## ⚠️ 先记住一条规则

```
发出命令后 10 秒内没有新命令 → 舵机自动松力
```

**所以每个动作序列要在 10 秒内发完。**
**停了很久想再动 → 先发 `servo arm`。**

---

## 一、基础命令

| 命令 | 作用 |
|---|---|
| `servo` | 显示用法 + 两路状态 |
| `servo status` | 只看状态 |
| `servo arm` | **两路都上电回中位**（最常用）|
| `servo center` | 两路回中位 |
| `servo stop` | 两路松力（不再吃电流）|

---

## 二、单路控制

```
servo pulse 0 1100     舵机1 转到 1100µs
servo pulse 0 1900     舵机1 转到 1900µs
servo pulse 1 1100     舵机2 转到 1100µs
servo pulse 1 1900     舵机2 转到 1900µs
```

**脉宽范围 1000–2000µs**：
```
1000µs ≈ 0°（一端）
1500µs ≈ 90°（中位）
2000µs ≈ 180°（另一端）
```

---

## 三、两路一起动

```
servo pulse 1100       两路都到 1100
servo pulse 1500       两路都到中位
servo pulse 1900       两路都到 1900
```

**注意**：只有一个数字时作用到**全部**舵机。

## 五、速度和角度说明

**舵机转速限制**：
```
5µs / 20ms  →  250µs / 秒
走 400µs（1500→1100）需要 1.6 秒
走 800µs（1100→1900）需要 3.2 秒
```

**所以命令发出后要等一会儿才到位**，别连续猛发。

**限幅保护**：脉宽只允许 1000–2000µs，
超出会报 `ERR: 角度超范围`，不会执行。

---

## 六、常见问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `ERR: 先 servo arm` | 超过 10 秒松力了 | 先发 `servo arm` |
| 舵机不动 | 脉宽没变 / 电源没接 | 发 `servo status` 看状态 |
| 舵机嗡嗡响 | 顶到机械限位 | 别用 1000/2000 极限值，留 50µs 余量 |
| 舵机抖动 | 5V 带不动 | 加 470µF 电容 / 用 ADJ 独立供电 |
| 开发板重启 | 舵机和开发板共用 5V | 舵机改用 ADJ 排针 |

## 七、状态怎么看

在网页终端发 `servo status`，或者看**画面预览**上舵机的状态上报。

```
servo0: pin=GPIO18 PWM=ON  cur=1100 target=1100 armed=1
servo1: pin=GPIO15 PWM=ON  cur=1715 target=1900 armed=1
        ↑            ↑      ↑           ↑            ↑
      编号        引脚   输出开关   当前值      目标值      是否通电
```

**`cur` 会慢慢追上 `target`** —— 这就是斜率限制在工作。
