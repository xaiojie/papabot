## 当前接口

- 坐标单位mm；X左右、Y前后（前为负）、Z向上。机身外宽124、高76；前盖外Y−26.2，主壳后Y68，后面板外Y70.6。
- PCB按native-rev-a中原80×32mm含天线U形开口的精确板框、4个Ø3.2孔生成参照。孔中心(5,5)、(75,5)、(75,27)、(5,27)。整机变换`X=u−40; Y=v−2; Z=w+66`，w=0为板底。
- PCB紧固件选小头M2×8，头径≤4mm；R06底盘连接仍为M3×10。原PCB孔不改，避免M3大头与J9排针外壳冲突。
- 屏幕保留91×44mm完整原板，标称孔距84.5×37.5mm。EC11和独立按键按用户确认后置，后续拆焊接线；玻璃约0.8mm内缩及60×43开窗需实物复核。
- 底盘4.6mm厚，Z30～34.6；电池目标75×40×20mm，放置Z35.6～55.6。R06横梁下方距目标电池3mm、距1mm上束带2mm。电池最终尺寸、≤80g重量和出线待商家确认。
- 每腿两个MG90S 180°，共8个；用原装舵盘和中心螺丝，打印件不含花键。耳孔为可调槽；同批舵机与舵盘未实测。
- R03集成后置控件、S1A、充电口、喇叭套和功放座；R09/R10充电板固定可单独调整。R14为可换麦克风托架，模块身份与外形仍待核。
- PCA9685、DFR0753和好盈UBEC采用开放支架加绝缘垫/扎带。DFR0753包络仅为空间预留，UBEC本体43×17×7mm不含导线和磁环。
- USB调试首轮通过拆后盖、松开右侧电源架接入主控USB；后面板Type-C为独立充电口，仍按关机充电。
