# INMP441 麦克风模块怎么接线（文字版）

模块 6 个针：**VDD  GND  SCK  WS  SD  L/R**

---

# 一句话结论

**接 4 根线到开发板 + L/R 接地：**

```
VDD  →  开发板 3V3      (L17 / L18 / L19 任意一个)
GND  →  开发板 GND      (L7 或 L20)
SCK  →  开发板 L4       (丝印 GPIO4)     ← 位时钟 BCLK
WS   →  开发板 L5       (丝印 GPIO5)     ← 帧同步 LRCLK
SD   →  开发板 L6       (丝印 GPIO6)     ← 音频数据
L/R  →  开发板 GND      (和 GND 接一起)   ← 选左声道
```

> ⚠️ **注意 SCK 和 WS 的顺序** —— 你之前写的是
> `SCK→GPIO5、WS→GPIO4`，**这两个要对调**：
> **SCK 接 GPIO4、WS 接 GPIO5**

---

# 为什么是这个顺序

固件设计文档里写死了（`语音指令与语音包设计.md` 第 237 行）：

```
MIC_BCLK = L4    MIC_WS = L5    MIC_SD = L6
```

而开发板左列的定义是：

| 位置 | 从左往天数 | 板上丝印 |
|---|---|---|
| L4 | 左列第 4 个 | GPIO4 |
| L5 | 左列第 5 个 | GPIO5 |
| L6 | 左列第 6 个 | GPIO6 |

**所以：BCLK→GPIO4、WS→GPIO5、SD→GPIO6**

---

# 逐针接线表

| 麦克风针 | 接到开发板 | 开发板位置 | 板上丝印 | 功能 |
|---|---|---|---|---|
| **VDD** | 3V3 | 左列第 17 / 18 / 19 个 | 3V3 | 供电 3.3V |
| **GND** | GND | 左列第 7 个 或 最下面那个 | GND | 共地 |
| **SCK** | GPIO4 | **左列第 4 个** | 4 | I²S 位时钟 BCLK |
| **WS** | GPIO5 | **左列第 5 个** | 5 | I²S 帧同步 LRCLK |
| **SD** | GPIO6 | **左列第 6 个** | 6 | 音频数据（麦→ESP32）|
| **L/R** | GND | 和 GND 并到一起 | GND | 选左声道 |

**共 6 根线（其中 VDD 和 L/R 都要接，别漏了 L/R）**

---

# 摆放姿势（和之前一样）

```
      天线（金属蛇形）朝上
      ┌──────────────┐
 左列 │  ESP32-S3    │ 右列
 L1→  │              │  ←R1
 L4→  │  ←SCK 在这   │
 L5→  │  ←WS  在这   │
 L6→  │  ←SD  在这   │
      │              │
 L20→ │              │  ←R20
      └──────────────┘
        USB 口朝下
```

**元件面朝上、天线朝上、USB 朝下，左列从上往下数第 4、5、6 个孔。**

---

# ⚠️ 先看你模块上的丝印顺序

**INMP441 模块的排针顺序各家不一样**，常见两种：

```
第一种：  VDD  GND  SCK  WS  SD  L/R
第二种：  VDD  GND  SD   WS  SCK L/R     ← SD 和 SCK 位置换了
```

**按模块上印的字接，不要按位置猜。** 拿不准就把丝印发我。

---

# INMP441 vs 设计文档里的 MSM261S4030H0

设计文档原来选的麦克风是 **MSM261S4030H0**，你手里是 **INMP441**。

**可以通用** ✅ 两者都是：
- I²S 数字输出
- **24 位数据装在 32 位槽里**（固件右移 8 位处理）
- 3.3V 供电
- 需要 L/R 脚选声道

**固件不用改。** 唯一区别是 INMP441 灵敏度略高一点点，不影响。

# 固件里的麦克风命令（2026-09-14 已实现）

`bringup` 工程已经内置 I²S 读取与电平测试，接线接好后直接用串口命令验证：

| 命令 | 作用 |
|---|---|
| `mic start` | 按 BCLK=GPIO4 / WS=GPIO5 / SD=GPIO6 初始化 I²S RX，16 kHz、32 位槽、24 位数据、左声道 |
| `mic read 50..3000` | 采一段音频，每 100 ms 打印一行电平，最后给结论 |
| `mic swap` | 把 BCLK / WS 对调后重装，用来判别丝印顺序是否接反 |
| `mic stop` | 释放 I²S 端口，引脚回到高阻 |

`mic read` 的输出列：

```
  300 ms  dc    86682  pk-pk    94912  ac-rms    18355    -53.2 dBFS  |############..................|
```

- **dc** 是直流偏置。MEMS 麦克风本身带约 1% 满量程的直流偏置，**不能直接拿总 RMS 当音量**，
  否则静音房间也会显示成 -40 dBFS。
- **ac-rms / dBFS** 已经扣掉直流，才是真正的声压电平。满量程是 24 位（8388608）。

`mic swap` 是个很有效的判别手段：**接对了才有数据，接错了（BCLK/WS 交换）会全零** ——
因为时钟错了麦克风就不会驱动 SD 数据线。2026-09-14 实测确认本项目的接线正确。

> ⚠️ 麦克风模块的排针顺序各家不一样，两种常见排列：
> `VDD GND SCK WS SD L/R` 和 `VDD GND SD WS SCK L/R`。
> 按模块上印的字接，别按位置猜；拿不准就用蜂鸣档量，或者接错了再用 `mic swap` 判别。

# 顺便：集成板上怎么接

集成板做好之后，麦克风**不接开发板**，而是插到**主板 J4**：

| J4 针 | 网络 | 对应麦克风 |
|:--:|---|---|
| 1 | MIC_BCLK | SCK |
| 2 | MIC_WS | WS |
| 3 | MIC_SD | SD |
| 4 | +3V3 | VDD |
| 5 | GND | GND |
| 6 | GND | L/R（并到 GND）|

**⚠️ J4 的顺序和麦克风模块的顺序不一样，要做一根转接线，不能直接对插。**
