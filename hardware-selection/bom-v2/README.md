## 电源方案的适配边界

本轮推荐候选结构：电池保护后输出 → 近电池保险/合格配电路径 → 负载开关 → 舵机降压和逻辑降压。两路输出均为5V，分别布线并共地，**两块降压的5V输出不并联**。舵机总电流不经过主控、PCA9685小板普通铜箔或杜邦线。

充电支路：外部5V/2A充电头 → TELESKY Type-C充电板 → 电池厂家定义的保护后充电接口；首版工作负载关闭时充电。没有电源路径管理电路，尚不支持边充边用。电池保护/均衡的定制要求和充电板实测电流仍按[电池选型记录](../power-selection-2s.md)核对。

DFR0753的6V最低输入意味着不能一直运行到电池BMS的深放保护阈值。可先以带负载约6.4V停止舵机动作作为调试起点，最终阈值、回差、断电方式和电芯保护必须一起设计；**该策略尚未实现，也未证明6.4V能覆盖所有瞬时压降**。8.4V、7.4V以及低电量区间都要验证5V输出、舵机起身瞬态和壳内温升。厂家“最大8A”不等于本机连续8A已验证；网页效率数值也不能直接用于2S工况。

用于筛选的计算：若舵机30W（5V×6A）加逻辑10W（5V×2A），按**假设85%效率**及6.4V电池输入，约需7.35A。若舵机达到模块标称8A上限，则总输出50W，同条件约9.19A，已接近定制包10A目标。这只是功率估算，不是峰值测试或实际效率证据。

保险7.5A暂用于器件方向和预算，须根据电池上限、线材/接点、保险时间电流曲线和实测起身浪涌调整；不能看额定电流就认定匹配。先验证两舵机单腿，再逐步验证八舵机、Wi-Fi、显示和音频同时工作。
