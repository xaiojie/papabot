## 逻辑降压和总开关的依据

[好盈官网](https://www.hobbywing.com/products/ubec-3a-2-6s99)明确列出：编号86010010，输入 **5.5–26V**，输出 **5V/3A 或 6V/3A**，跳帽切换，名义 **43×17×7mm、11g**。本机采用5V档，逻辑/屏幕/音频合计按5V/2A目标设计，比第二块DFR0753节省20元。它与旧报告排除的“UBEC 10A-Car、无5V档”是不同产品。

**到货先断电把跳帽设到5V，并空载测压后再接电子模块。** 厂家纹波小于50mVpp只对应12V输入、2A负载，不能写成2S电池下已测结果。安装须留引线、磁环和跳帽空间；保留原厂输入输出引线，核对极性后焊接/转接，不能用FIT0030承载整条逻辑路电流。

[NKK S1A官网规格页](https://www.nkkswitches.eu/products/Toggles/Toggles%20S/S1A/)列出 SPST、ON-OFF、15A(AC/DC)、30VDC、非发光、焊片及面板孔 **Ø12.5mm**。部分分销商写20A/DC，本版采用官网较保守的15A/DC表述，已高于本机工作母线设计电流；不把AC额定推导成DC额定。S1A本体比微型滑动开关大，后面板需按开关体、焊片、螺纹长度和操作空间布局，尚未修改CAD。

## 接线方案

```text
电池包保护后的 P+ ─ 保险 ─┬─ S1A总开关 ─┬─ DFR0753 ─ 舵机5V外部配电
                         │             └─ 好盈86010010（5V档）─ 逻辑/显示/音频
                         └─ 充电板 BAT+
电池包保护后的 P− ────────── 充电板 BAT− / 两路降压及信号共地
```

首版仍为**关机充电**。充电板接在开关前受保护节点，关掉S1A即可断开两路电池工作负载。两路5V输出不并联；外接调试USB可能另行给主控供电，调试接法需避免回灌。

原F05“高边负载开关与控制器小件”5元预留取消：S1A直接承担机械断开，已不需要该套手动控制器件。**本版不提供独立电子自动低压断电**；暂以负载下约6.4V停止动作并提示手动关机为起点，停动作不等于切断舵机电源。F06采样、回差和阈值还需电路/固件及压降测试，包内每节过放保护仍必须具备。不能等电池BMS动作才保证DFR0753处于≥6V输入范围。

PCA9685的VCC与I²C上拉都用3.3V，和ESP32共地；上电默认OE禁用方案计入F07，按到货板确认相关焊盘。仅从PCA小板引出PWM信号，8个舵机的正电源走外部配电通路，不经过PCA板上V+总线或ESP32开发板。

FIT0030是可直接插接的成品信号线；FIT0585是用于短电源段的硅胶线，需要裁切、焊接和绝缘。8个MG90S的自带线复用，电池定制要求已含XT30配对件，额外购买数量为0。主干18AWG按实际压降、成束和端点温升验证，不将网页22A宣称当作整机额定。载板排针、热缩管仍保留在其他辅料需求中；这份采购选择不表示整机线束已经加工或压接完成。
