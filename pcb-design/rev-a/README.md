## 已确认的电气事实

**主控USB与5V排针直接相连。** 厂家公开原理图第2页（图框2024-02-28）显示 Type-C U13 VBUS 与 J1.2/3/4 同接 `+5V`，U6 ME6217C33M5G 将该网络降至3.3V，图中没有电源选择或反向阻断器件。[原页证据](sources/lckfb-schematic-core.jpg)。外接5V与普通USB VBUS不得同时直连；单在外供一侧串二极管仍不能阻止向电脑回灌。

**屏幕工作电压为3.3–5V，BLK可不接、默认全亮。** 所选 TOUGLESY 2.4寸 ST7789＋EC11 商品规格图已确认上述两项。Rev A 的 VCC接 `+5V_LOGIC`，SPI使用3.3V，BLK留空；载板J3第8脚也不接线。这不证明信号脚有5V容限。模块工作电流、物理针序与3.3V SPI实际稳定性仍需在收货后确认。[供应商图](sources/selected-display-module-spec.png)。

**主控尺寸和针序已有原厂依据。** 板体51.66×20.32mm，两排20P、节距2.54mm、列距17.78mm、首末孔距48.26mm。项目位置Ln/Rn按“元件面朝上、天线上、USB下”从上到下编号；厂家原理图左排J2、右排J1由下往上编号，故Ln＝厂家J2.(21−n)，Rn＝厂家J1.(21−n)。原生排母Pin 1朝向必须对应其实际封装。

**19个GPIO没有重复分配。** 避开启动配置0/3/45/46、USB19/20、UART43/44、内存26–37与板载LED48。ADC用GPIO1/ADC1_CH0；两个I2S时钟组分别用于麦克风与功放。

## 供电与首次上电核验

1. **首次USB烧录：把主控从载板完全取下，单独接电脑USB。** 烧录结束断开USB，再装回载板。整机使用电池供电时勿插USB。
2. **JP1、JP2都是人工可断开线桥，初次上电先保持断开。** 分别用于切断主控外供5V和电池采样路径；它们不是自动防回灌或自动电源切换电路。
3. **先核电源再连接负载。** 确认两路降压均为5V，好盈跳帽处于5V档；核对极性、主控3.3V、接口电压、静态电流及ADC节点电压，按分阶段上电结果分别接通JP1/JP2。改接线桥时断电。未完成实测前不把正常电压或上电行为写成已通过。
4. **电池采样从总开关后取电。** 100k/33k＋100nF在8.4V时输出名义2.084V，1%电阻最坏约2.116V；等效阻抗24.8kΩ、RC约2.48ms。JP2可断开采样，供电瞬态中3.3V未建立时的ADC注入仍需分析与测试，100k限流不等于自动满足芯片额定。
5. **舵机逐只卸载测试。** OE先保持高，核PCA模块实际下拉及I2C上拉电源，再配置频率与零输出、自检后使能；验证复位、低电量、八舵机动作电流和温升。OE只禁止PWM，不切断舵机电源。

首版采用关机充电；电池保护后P+经过7.5A保险，再分至充电板与S1A总开关，开关后分两路降压。充电板负端接保护后的P−，不绕过BMS。`+5V_SERVO`与`+5V_LOGIC`禁止并联，舵机回流走独立粗线返回舵机电源；电气共地不等于共用细回路线。

## 仍需实物确认

- HANLI PCA9685板的OE下拉、I2C上拉阻值与物理脚序；外加10k不能直接假定压过板载下拉。芯片MODE2拟用OUTNE=00、OUTDRV=1、INVRT=0；0x40只对应A0–A5全低。
- 所购麦克风的确切板型：DFRobot SEN0327 HTML为直径14mm、1.8–3.3V；所链PDF却是Sipeed I2S_Mic、矩形15.24×9.14×11.2mm。相同MSM261S4030H0芯片不能证明同一块板。3.3V I2S功能映射可继续，实际针序以实物为准。
- MAX98357模块的A/B版本、SD_MODE/GAIN及上电静音配置。功放VIN走独立5V线，喇叭接BTL的SPK+/SPK−，任何一端都不接地。
- 后置EC11与独立键拆下后的公共端和无源触点针序。A/B/两键各10k上拉3.3V，不将原屏控件焊盘自动并入新接口。
- DFR0753实际焊盘、充电电流/反向漏电、定制电池保护与均衡参数，以及外部保险座安装、支路插座、线径和温升。目标舵机5V/6A必须结合低电量与堵转情况验证。

## 结构与后续发布

3D工作暂停。主任务原生布局已将天线端设为u=14.17mm，采用U形槽u=0…24.17、v=9.5…22.5mm；实际PCB记录优先。`board-interface.*`保留80×32×1.6mm、四孔Ø3.2的A1候选，坐标变换X=u−40、Y=v−2、Z=w+64，四孔中心(5,5)、(75,5)、(75,27)、(5,27)。其放置只是空间候选，不能据此声称原生21元件PCB的连接器、天线、USB维护空间、线束弯折与高度都已经校验。实际板框、元件位置及DRC以主任务正在维护的原生工程为准。

外部高电流供电及MINI PCB保险座仍需有额定且可靠的安装方式。完成原生ERC、PCB布线/DRC、供电承载和装配核验后再发布Gerber、钻孔、BOM与装配图。本包的检查不代替这些制造检查。

`python3 build-review.py`可重生成本包JSON/CSV/SVG和数据检查，已同步本次证据，不会恢复旧的屏幕电压/BLK未知项。PNG需由对应SVG重新渲染。该脚本不会操作EDA。
