# 资料来源与适用范围

- `revb-screen-interface.json`：2026-09-09 当前项目 `pcb-design/native-rev-b/screen-interface.json` 的快照。屏幕只用3.3V；原RevA的5V屏幕接法不再使用。
- `lckfb-pin-locations.csv`：从项目 `pcb-design/rev-a/01-controller-pinout.csv` 提取位置、厂家针号和丝印三列；未带入旧版功能/供电说明。元件面朝上、天线在上、USB在下，左右各20针由上到下。本表仍须与到货板版次核对。
- 开发板原理图：立创公开资料 `SCH_立创ESP32S3R8N8开发板原理图.pdf`（项目原始参考图为 `pcb-design/rev-a/sources/lckfb-schematic-core.jpg`）。UART0接CH340K；USB VBUS直接连5V排针；LED GPIO48低有效，BOOT GPIO0低有效。原始下载入口：https://wiki.lckfb.com/zh-hans/esp32s3r8n8/download-center.html
- 屏幕供应商提供的ESP8266示例使用Adafruit_ST7789、`init(240, 320)`与`setRotation(3)`。这里只采用芯片驱动/初始化方向参考，不复制ESP8266的GPIO编号。用户资料目录：`/Users/jay/Downloads/2.4寸TFT彩屏+EC11旋转编码器模块`，项目已有副本在 `pcb-design/native-rev-a/supplier-review-2026-09-09/sources/程序/ST7789/ESP8266/sketch_aug07a/sketch_aug07a.ino`。
- 固件库：PlatformIO espressif32 6.12.0 https://github.com/platformio/platform-espressif32/tree/v6.12.0 ，Arduino-ESP32 2.0.17与Adafruit ST7789/GFX/BusIO。精确包版本与构建记录见验证报告。

以上资料支持接口设计与编译准备；并不证明实物版本、焊接、电源电流、信号质量、机械配合或动作范围已验证。
