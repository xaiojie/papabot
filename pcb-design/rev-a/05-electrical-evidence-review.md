# Rev A 电气证据补充（2026-09-08）

本轮已取得厂家原理图预览，确认所公开版本的主控板 **USB VBUS 与 5V 排针直接相连，没有板载电源隔离**。同时，所选屏幕模块的供应商规格图明确支持 3.3–5V 供电，BLK 可以不接、默认全亮。下列结论已同步给负责原生电路绘制的主任务。

## 1. 主控板 USB 与外部 5V

来源链：

1. 厂家资料中心：<https://wiki.lckfb.com/zh-hans/esp32s3r8n8/download-center.html>
2. 其公开资料分享：<https://pan.baidu.com/s/191qHjphKNeRITbFmC6Ct-g?pwd=hoga>
3. 文件夹 `立创·ESP32S3R8N8开发板资料-240926 / 第02章.【立创·ESP32S3R8N8】开源硬件`
4. 文件 `SCH_立创ESP32S3R8N8开发板原理图.pdf`，网页列示 945 KB、2 页，文件夹日期 2024-09-26。原理图图框创建/更新日期均为 **2024-02-28**。

已在浏览器正常打开公开预览，并通过页面资源导出保存两页原始预览图片：[封面](sources/lckfb-schematic-cover.jpg)、[第 2 页 core 电路图](sources/lckfb-schematic-core.jpg)。本地保存的是百度公开 PDF 预览的 JPEG 页面，**不是原 PDF 文件**。

第 2 页可直接读到：

| 位置 | 原理图连接 | 含义 |
|---|---|---|
| 左下 TYPE-C 区 U13 | VBUS A4/A9/B4/B9 直接接 `+5V` | USB VBUS 没有串联隔离器件 |
| 右下排针区 J1 | 2、3、4 脚直接接 `+5V` | 外部 5V 排针与 USB VBUS 同网 |
| 下方电源区 U6 | ME6217C33M5G，VIN/CE 接 `+5V`，VOUT 接 `3V3`，标注 800 mA | 共用板载 3.3V 稳压器；800 mA 是器件标注，不代表全部可供外设使用 |
| USB HUB 区 U16 | CH334F；UART 区 U24 为 CH340K | 与商品说明中的一个 Type-C、两个通信通道一致，不能据此推导电源隔离 |

**设计结论：**外接 5V 与普通电脑 USB 的 VBUS 不得直接同时接入。仅在外部 UBEC 一侧串联一颗二极管，仍会存在“外部供电 → 开发板 +5V → USB VBUS → 电脑”的路径，不能保护电脑。若要支持同时供电调试，必须能实际断开/隔离 USB VBUS 路径并验证两路供电及外设 I/O 的时序；载板只有 5V 排针，不能通过载板上的单颗二极管解决开发板内部直连。

主任务现已确定首版操作约束：首次 USB 烧录把主控从载板完全取下，单独连接电脑；装机电池供电时勿插 USB。原生 `JP1`（审阅名 `JP_MCU`）是主控外供 5V 可断线桥，`JP2`（`JP_SENSE`）是电池采样可断线桥，两者初次上电保持断开，按分阶段供电测量结果再接通。线桥与拔板烧录方法不等于自动隔离电路；本版不宣称支持装机电池供电同时直插 USB。

以上结论适用于厂家发布的该版电路；收货后应核实板卡版本，并在断电状态测 USB VBUS 与 5V 排针通断，确认所购实物没有改版。

## 2. 主控排针编号

厂家原理图使用右排 `J1`、左排 `J2`；两个排针均由下往上编号 1→20。项目原有位置坐标以“元件面朝上，天线在上，USB 在下”为准，从上往下编号 `Ln/Rn`，因此：

- `Ln = 厂家 J2.(21−n)`。
- `Rn = 厂家 J1.(21−n)`。
- 厂家 J1.2/.3/.4 为 +5V，J2.2/.3/.4 为 3V3；两排第 1 脚均是底部 GND。

这可用于两只独立 20P 排母的映射。实放 C429947 时仍需核原生封装的 Pin 1 朝向；本轮没有修改主任务的原生符号、封装或 PCB。

## 3. TOUGLESY 2.4 寸 ST7789 + EC11

来源是项目已有、与所选商品一致的供应商规格图。已保持原图内容复制到 [selected-display-module-spec.png](sources/selected-display-module-spec.png)，逐项记录见 [selected-display-module-evidence.json](sources/selected-display-module-evidence.json)。

图片明确给出：ST7789、320×240 RGB、无触摸、SPI、**工作电压 3.3–5V**；`BLK：TFT背光调节，默认全开，可以不接`。功能端名为 GND/VCC/SCL/SDA/RES/DC/CS/BLK/A/B/PUSH/K0。

按主任务决定，Rev A 采用：

- VCC 接 `+5V_LOGIC`，SPI 用 ESP32 的 3.3V 信号。
- BLK 不接，使用默认全亮。载板 J_LCD 第 8 脚也独立留空，不接任何电源、GPIO 或背光线。
- 后置 EC11 与独立按键方案保持原有设计；不能仅凭“独立于屏幕”就认定原板公共端、上拉电源和物理针序已知。

这份规格图没有证明信号输入具有 5V 容限，没有给出 BLK 输入电流/阈值，也没有给出模块工作电流。Rev A 不向信号脚施加 5V、不直接驱动 BLK；在实际模块上确认 3.3V SPI 能稳定工作，并检查 5V 电源预算。图中未能可靠读出物理排针的数字编号和观察方向，因此载板自定义 1×8 顺序仍不能冒称厂家针序。

## 6. 陶瓷天线位置与载板保守候选

厂家尺寸资料第2页正面图明确用箭头标出陶瓷天线，位于无USB一侧的短边中央，沿板宽方向放置。[完整来源](sources/lckfb-page-02-Im0.jpg)，[同图局部放大](sources/lckfb-antenna-detail.png)。

按图片近正投影正面板框约 x=369…869 像素、板长51.66mm估算，缩放约9.7像素/mm；陶瓷天线约 x=840…865，所以沿长轴距天线端板边约 **0.4–3.0mm**，本体横向长度约 **6–7mm**。天线旁的匹配/相关器件延伸至该端约 **6–8mm** 区域。照片不是工程外形图，这些数值仅用于划出保守空间，不能作为封装制造尺寸或射频合格证据。

针对80×32mm载板和两只独立排母，建议优先保留一个**向天线侧载板外边敞开的中央U形缺口**，减少天线正下方的新增板材和铜；两侧留排母支撑条。候选沿长轴覆盖从天线端向USB方向10mm，开口横向先取约13mm、以主控宽度中心对称。17.78mm排距下，开口边距两排针中心各约2.39mm；仍需按实际排母焊盘、1.2mm钻孔、板厂槽铣圆角和受力检验，不能直接把较宽的16mm概念区域当成可加工缺口。

若保持旧A1候选中主控天线端u=8、横向中心v=16，则上述U形缺口候选为载板局部 **u=0…18、v=9.5…22.5mm**；主任务已将实际天线端改为u=14.17，采用U形槽u=0…24.17、v=9.5…22.5mm；本段前述u=8仅解释旧A1坐标。缺口区域不应有任何铜层、走线、过孔或器件。缺口外的天线周边也避免新增铜、金属螺母、电池和粗电源线，能向自由空间布置时优先这样处理。

这是供原生PCB布局使用的保守工程提案，**不是厂家规定的天线禁布尺寸**。目前没有该陶瓷天线料号与其参考地平面/净空规范，也没有模块完整PCB铜层文件，因此无法由照片保证射频性能。切勿为消除覆盖冲突删除必要排母焊盘；若空间不足，应调整放置/板框，再做实际WiFi/BLE信号与整机干扰对比。3D工作继续暂停；本轮不修改原生钻孔，API读出缩放差异不作为改孔依据。
