## 本次原理图修复

原单页拆成五张功能分区明确的原生图页，元件、标题、说明和网络标签统一对齐。当前顺序为：

1. `01_电池保护与均衡`：HY2120-CB、背靠背 MOS 和两节 HY2213-BB3A 均衡。
2. `02_USB充电`：USB-C 5V 输入、IP2326 2S 升压充电、NTC、使能及状态指示。
3. `03_配电与主控`：保险丝、外置总开关、两路降压接口、ESP32-S3 插座和电池采样。
4. `04_显示音频与交互`：独立 3.3V 屏幕支路、I²S 接口和单独的 EC11。
5. `05_八路舵机驱动`：PCA9685、OE 默认禁止输出、八路统一引脚定义的舵机接口。

除布局外，修复了保护 MOS 源漏/栅极连接、检测滤波、均衡器型号与驱动脚、充电 VSYS/VOUT 分离、供电隔离和部分错误的器件/封装。具体电路修复过程保留在 [阶段记录](../repair-2026-09-12/修复与检查记录.md)。

**新屏幕为 HS24S010B / C5329587，本身不带旋钮或按钮。** 主板 J3 使用真实的 XH-10A / C2908608 连接器，通过线束连接屏幕；已移除把整块 LCD 模组当作主板器件的旧封装。EC1 是单独的 EC1106S 编码器，位于主板右下方。没有额外的旧屏 KEY0 按钮。

## 后续编辑注意

**本版接地铜皮为原生、可编辑的静态 Fill 多边形，不能随走线自动重算。** 当前 EDA 版本的 Pour 重建接口与界面重建均遇到故障，因此使用 10 个已检查的 GND 填充区域和 46 个缝合过孔完成当前版。最终原生 PCB 不含未生成的 Pour 占位对象。

移动器件、改变板框或修改走线后，需要从最新焊盘、线路和净空重新生成接地铜皮，再运行连通性/间距 DRC 和制造文件核验。不要直接重跑 `layout-2026-09-12/` 中的历史布线、导入或填充脚本，它们记录特定阶段状态，可能覆盖后续修改。继续编辑请打开本目录 epro2，并先保存新的备份。

Gerber 中 `Copper Areas: 0` 指自动 Pour 对象数量；当前接地铜皮以 `SolidRegion` 导出，已做实际多边形覆盖核验。单独的 Via 钻孔文件是完整 PTH 文件的子集，不是额外需要重复钻的孔。

## 尚未验证的实物事项

设计文件和检查已完成，尚未进行本版打样下单、付款、焊接、实物充放电、温升、满负载舵机测试或结构试装。当前 110×75 mm 主板与原 80×32 mm 载板的固定结构不同；新屏幕、EC11、外接模块、线束和插头空间需要纳入整机结构。

IP2326 的 R8=255kΩ 对应约 0.353A，是公式计算值，低于手册典型 0.5A 示例范围，须在连接实际电池前验证恒流、截止、超时与 NTC 动作。2S 保护/均衡阈值、MOS 温升、舵机启动压降及电源模块输出也须逐项验证。没有以 DRC 通过宣称整机已可安全运行或持续承载 8A。
